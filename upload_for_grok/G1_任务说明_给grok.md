# 给 Grok 的派单：F 组社区一手材料取证

> **这是给你的任务说明，和 `G2_事实底账.md` 一起上传。**
> 你不需要读代码，不需要提出 30 条假设。你的产出是一张**证据表**。

## 一、你的任务不是发散，是取证

项目已有 4 份基于文档的分析报告（分别由不同模型独立完成），但它们有一个**共同的空白**：没有一份有像样的社区一手材料。任务书要求"跨平台搜集 X/Reddit/Bitcointalk/Telegram/YouTube/B站/知乎/贴吧/交易论坛"，四家都没做到。

这个空白由你来补。你的价值在**材料**，不在假设。

**为什么选你**：项目文档 `OBSERVATION_PLAN.md` §12.1 已核实，Grok 官方产品页明确列出实时网页搜索、**实时 X 整合**、来源引用。§12.2 的建议是"市场现场与公开讨论搜集 —— 先试 Grok"。

**但请注意边界**：
- ✅ 你擅长的是 **X/Twitter 上的实时讨论、原始帖子、时间戳、传播链**
- ❌ 你不必去找学术论文或交易所公告（那是通用搜索的活）
- ❌ 不要读代码做精确断言（长文本精读不是你的强项）

## 二、要采的四类材料

**每类至少 5 条，合计 ≥20 条。**

### 第 1 类 · 真实交易者的判断过程（≥5 条）

某人在某个币启动**之前**说了什么。**必须有时间戳早于价格启动。**

- 如果能找到"事前"的帖子，注明发帖日期与币价启动日期，证明时间顺序。
- 如果只能找到"事后复盘"，**明确标注"事后复盘，不能证明提前发现"**——这类仍然有价值（能看出他怎么解释自己的判断），但不能当提前发现的证据。

### 第 2 类 · 失败案例（≥5 条，**最重要**）

某人的方法**怎么失败的**、他自己怎么复盘。

任务书明确要求找"某个交易方法如何失败"，而不是"最佳交易策略"。这类材料最难找，但价值最高——**因为成功故事会被人反复讲，失败案例只有当事人愿意写**。

要找的形态：
- "我以为这个要涨，结果没涨"的公开复盘
- "这个方法我用了两年，后来失效了"的反思
- 社区里对某个流行方法的**证伪**讨论

### 第 3 类 · 观点分歧（≥5 条）

两个都拿出证据的人，结论相反。要**双方原话**，不要转述。

### 第 4 类 · 小众方法/数据源的真实测试（≥5 条）

有人实际测过某个指标或数据源，结论是什么——**包括测了发现没用**。

## 三、每条必须给的字段

| 字段 | 要求 |
|---|---|
| 平台 | X / Reddit / Telegram / YouTube / B站 / 知乎 / 论坛 / 博客 |
| 作者 | handle 或 ID，**不许编** |
| 发布日期 | 精确到日，**不许用"最近""前段时间"** |
| 原文引用 | **≥2 句，不许改写、不许概括** |
| URL | 可点击的原始链接 |
| 证据等级 | 一手原始 / 二手转述 / 无法核验 |
| 是否事前 | 早于价格启动 = 是；否则写"事后" |

## 四、硬约束（违反任一条，整份材料作废）

1. **找不到就写"无法访问"，不许用记忆补，不许编造 handle 或日期。**
   如果你记得某个说法但搜不到原帖，写"记得有这种说法，但检索不到原始出处，证据等级：无法核验"。

2. **转发很多次 ≠ 多个独立来源。**
   同一说法被 10 个人转发，只算 1 条。要标出"原始出处是谁"。

3. **历史暴涨案例的结局可能已在你的训练数据里。**
   涉及 2023 年以前的币，你要特别小心：你"知道"它会涨，不代表当时有人能预判。凡涉及历史案例，必须标注这一点。

4. **不要给结论、不要给建议、不要写研究报告。**
   你只交材料。判断由别人做。如果你有想法，单独放一节"我的观察（非证据）"，并且不要混进证据表。

5. **不要美化任何交易者。**
   任务书明确禁止"编造历史交易者的发言、社区业绩"。你引用的每一句话都必须能点开原文。

## 五、六个待查问题（决定你去搜什么）

这六个问题来自项目当前最缺的材料。**按顺序做，做不完就停在能做完的地方，不要为了凑数降低标准。**

### Q1 · 有没有人"事前"说过某币要涨？

要的是：**发帖时间早于启动**，且给出了理由。理由属于哪一类（筹码结构 / 叙事 / 技术形态 / 事件驱动 / 跨所套利 / 纯直觉）？

这直接关系到项目的一个核心争议：**多倍币到底能不能提前发现**。

### Q2 · 有没有人公开复盘过"我以为要涨、结果没涨"？

他的误判点在哪？是看错了指标，还是忽略了某个他没看的东西？

**这条比 Q1 更重要**——项目现在最缺的是失败样本。

### Q3 · "低流通 / 高 FDV 会暴涨"这个说法，有没有人被实测证伪过？

背景：项目里另一份研究认为"低流通→大幅上涨"在公开文献里**不存在正证据**。需要社区侧的材料来印证或反驳。

### Q4 · 有没有人系统测过订单流指标在加密里的有效性？

具体指：`taker buy` 占比、主动买入/卖出比、单笔平均成交额、CVD（累计成交量差）。

要的是**实测结论**，不是"我觉得有用"。测了发现没用的同样有价值。

### Q5 · "洗盘"和"派发"在实战中怎么区分？

有没有人给过**可操作的标准**（具体到量价、持仓、费率），还是都停留在"看盘感"？

背景：项目有 841 个历史事件，其中 468 个是"涨上去又跌回来"——这正是洗盘/派发判断错误的代价。

### Q6 · 有没有人讨论过"庄家故意画出完美技术形态来出货"？

有没有具体案例？如果量化筛选器普及后这种行为变多了，有没有人观察到这个变化？

## 六、交付格式

一张 Markdown 表，四类材料分四节。示例：

```markdown
## 第 2 类 · 失败案例

### F-01
- 平台：X
- 作者：@xxxxx
- 发布日期：2025-03-14
- 原文：「……」「……」
- URL：https://x.com/xxxxx/status/...
- 证据等级：一手原始
- 是否事前：事后复盘
- 一句话说明：该作者认为自己误判的原因是只看了 OI 增长，没看现货成交量
```

最后附一节 **"无法访问的平台"**，列出你尝试过但打不开的来源（Telegram 私密频道、已删帖、需登录的论坛等）。**这一节不是免责声明，是证据边界的一部分**——别人需要知道哪些地方是空的。

## 七、额度提醒

F 组取证很耗搜索。建议分 3 批做，按价值排序：

1. **先做第 2 类（失败案例）** —— 最有价值、最难找，先确保这块
2. 再做第 1 类（事前判断）
3. 最后做第 3、4 类

**做不完就交已完成的部分，并说明停在哪。** 半份真材料比一份凑数的完整材料有用得多。
