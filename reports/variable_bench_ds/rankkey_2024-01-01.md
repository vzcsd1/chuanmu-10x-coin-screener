- 候选池：`score >= 5.0`（策略实际会买的东西）

- 每档 = 按该键把池子分五档，`Q5` 是键的最高档（会被优先买的那批）

## 判定规则

| 现象 | 含义 |
|---|---|
| `Q5−全池` < 0 | 这个键把差的东西排到了前面，**在扣分** |
| `Q5−Q1` < 0 | 排序方向是反的 |
| `Q5−全池` > 0 且 `IC7` > 0 | 这个键值得当排序量 |
