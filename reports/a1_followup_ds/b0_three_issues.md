## ① 评分缺失语义：在线「逐项」 vs research/11「整组不计」

| | 事实 |
|---|---|
| 生产实现 | `deriv_score` **逐项**判断：`oi_chg_1d` / `oi_chg_3d` / `ls_top` 各自有值就各自计分，缺哪项少哪项 |
| `research/11_hit_rate_current.py` | 要求**三列同时有值**才计分，否则整组按 0 处理 |

独立复算（同一样本、同一门槛）：

| 指标 | 逐项语义 | 整组语义 |
|---|---|---|
| 上涨事件命中率 | 0.7494 | 0.7494 |
| 判定翻转事件数 | **0** | |
| 合约指标部分缺失的上涨事件 | 4 / 822（**0.49%**） | |

**影响**：语义差异真实存在，方向也确定（逐项只会多、不会少），但在本样本上
**不改变任何一条结论**——缺失太罕见，翻转数为 0。原报告结论无需改写，只需在引用处
标明两种语义曾并存。

## ② 横截面排名的日期覆盖

`research/08_audit_hindsight.py` 的全市场日收益矩阵来自 `data/1d`。

| 项 | 实测 |
|---|---|
| `data/1d` 标的数 | 619 |

| 样本行数 | 1,402 |
| 拿到 `rank_1d` 的行 | 1,402（缺失 0） |
| `pre_day` 落在覆盖之外的行 | **0** |
| 标的不在 `data/1d` 的行 | **0** |

**影响**：本样本上覆盖不构成问题，原排名结论可用。但**口径本身要保留**：
覆盖之外必须按「缺失」处理，不能当作「不满足 `top10_gainer`」——否则会把资料不足
误记成策略性排除。这一条与包 1 的「缺资料 ≠ 明确不达标」是同一纪律。
