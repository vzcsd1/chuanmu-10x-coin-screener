> **标签口径**：A17 可交易性清洗。正例只保留「买得进 + 拿得住」的真赢家，不可交易正例并入负例；1h 缺失、无法判定的正例已剔除。清洗后 label=1 共 785 条 / 全样本 1401 条（清洗前正例 821 条）。

- 生成脚本：`research/14_variable_bench.py`｜明细：`data/variable_bench.csv`
- 零分布校准：每个变量打乱 200 次｜判定门槛：有效样本 ≥ 200
- 主判定期：7 天（n 最大且不含标签污染）｜次判定期：14 天

## 读法

| 列 | 含义 | 怎么用 |
|---|---|---|
| `auc` | 区分「会翻倍」vs「不会」 | >0.55 且超出零分布 95% 才算有 |
| `ic7_all` | 与未来 7 天净收益的相关 | 正=方向对 |
| `pIC7_all` | 扣掉 ret_1d/ret_7d/score 后的偏相关 | **这才是新增信息** |
| `ic7_l1` | 爆拉组内部 IC | 避免被正例比例污染 |
| `r_ret1d` | 与「前一日涨幅」的相关 | >0.5 = 只是动量换皮 |
| `q5spread7` | 爆拉组内五分位收益价差 | 排序能力 |

**零分布带**：`auc_p05/p95`、`pIC7_p05/p95`。真实值落在带内 = 没有信息。
