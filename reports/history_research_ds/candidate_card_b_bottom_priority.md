## 1. 背景：现有排序在横截面上不携带信息

把「未来 30 天内最高价 ≥ 2×/3×/10×」当作标签，对**每小时全市场横截面**排序，
看排在前 N 的币命中率相对基准的倍数（lift）。分母已修正为「小时数 × N」。

| 排序依据 | ≥2× P@20 | ≥3× P@20 | ≥10× P@20 | 训练段 2022–2024 | 复核段 2025–2026 |
|---|---|---|---|---|---|
| **`score_total`（现行）** | **1.01×** | **1.01×** | **0.95×** | 0.95 / 0.91 / **0.59** | 1.19 / 1.24 / 1.39 |
| `score_kline` | 0.99× | 0.95× | 0.98× | — | — |
| `score_deriv` | 1.03× | 0.94× | 1.14× | — | — |
| `trend`（收盘>EMA50） | 1.00× | 0.89× | 0.96× | — | — |

**提高门槛也不提升质量**（同样口径）：

| 门槛 | 占可评分格 | ≥2× 命中率 | ≥10× 命中率 |
|---|---|---|---|
| 基准（全部可评分） | 100% | 12.14% | 0.11% |
| `>=5`（现行） | 47.2% | 11.56% | 0.098% |
| `>=8` | 11.8% | 11.53% | 0.082% |
| `>=10` | 5.8% | 11.72% | 0.081% |
| `>=12` | 3.4% | 11.90% | 0.066% |

→ **靠提高分数或换用现有分项来减少关注数量，证据不支持。** 这是本卡存在的理由。

## 2. 做什么

新增一个**独立于评分**的排序量，作为「名单内先看谁」的依据：

| 特征 | 定义（全部因果，只用 ≤ t 的数据） | 方向 |
|---|---|---|
| `dist60h` | `close_t / max(high[t-1439..t]) - 1`（距 60 日高点） | **越小越好**（离高点越远） |
| `ret30d` | `close_t / close[t-720] - 1`（前 30 日涨幅） | **越小越好** |
| `boxwidth` | `(max(high)-min(low)) / mean(close)`，窗口 168h | **越大越好** |

本卡**只测排序**，不改生产评分；先把这三个量与现有 `score_total` 并列输出，供对照。

## 3. 证据（主时段 2022-01-01 ~ 2026-09-30）

### 3.1 单特征横截面 lift（P@20，全样本）

| 排序 | ≥2× | ≥3× | ≥10× |
|---|---|---|---|
| **`dist60h` 升序（越低于 60 日高点）** | **1.60×** | **1.61×** | **1.86×** |
| `ret30d` 升序 | 1.48× | 1.60× | **2.11×** |
| `ret7d` 升序 | 1.34× | 1.35× | 1.57× |
| `boxwidth` 降序（箱体越宽） | 1.34× | 1.36× | 1.28× |
| `qv24` 升序（24h 成交额越小） | 1.13× | 1.32× | 1.78× |
| `volratio`（量比） | 1.03× | 1.07× | 1.33× |

**反向侧（证明不是噪音，而是单调方向）**：

| 反向 | ≥2× | ≥3× | ≥10× |
|---|---|---|---|
| `dist60h` 降序（越接近/超过高点） | 0.40× | 0.42× | **0.14×** |
| `boxwidth` 升序（箱体越窄） | 0.34× | 0.39× | 0.20× |
| `qv24` 降序（成交额越大） | 0.55× | 0.56× | 0.83× |

来源：`supplementary_feature_lift_lag0.json`。

### 3.2 时间切分（防过拟合的关键）

训练段 = 2022–2024，复核段 = 2025–2026（两段都被旧研究接触过，只称探索/复核）。

| 候选 | 训练 ≥2× / ≥3× / ≥10× | 复核 ≥2× / ≥3× / ≥10× |
|---|---|---|
| `score_total` | 0.95 / 0.91 / 0.59 | 1.19 / 1.24 / 1.39 |
| **`dist60h` 升序** | **1.48 / 1.48 / 1.91** | **1.96 / 1.92 / 1.80** |
| `ret30d` 升序 | 1.34 / 1.33 / 1.36 | 1.88 / 2.24 / 3.06 |
| `combo3`（三者等权分位平均） | 1.50 / 1.40 / 1.17 | **1.98 / 2.30 / 3.95** |

- **`dist60h` 升序是唯一在两段都稳定、且 10× 档也稳定的候选**（1.91× → 1.80×）。
- `ret30d` 与 `combo3` 复核段更强，但训练段较弱，**尚不能称已稳**。
- `score_total` 在训练段是**负 lift**（0.59× @10×），复核段转正——**方向不稳定**。

来源：`supplementary_time_split_lag0.json`。

## 4. 必须同时接受的代价（不得只报 lift）

`dist60h` 升序是**「粘性」名单**（同一批深跌币长期占榜），因此**召回显著下降**：

| 排序 | N=20 覆盖 ≥2× / ≥3× / ≥10× | N=30 | N=40 |
|---|---|---|---|
| `score_total` | 84.7% / 80.8% / 74.1% | 93.2% / 90.5% / 85.2% | 96.9% / 94.4% / 92.6% |
| **`dist60h` 升序** | **20.0% / 19.7% / 29.6%** | 27.2% / 26.2% / 40.7% | 33.3% / 32.1% / 44.4% |
| `combo3` | 34.5% / 33.1% / 44.4% | 45.2% / 42.1% / 51.9% | 52.6% / 49.8% / 51.9% |

→ **不能把 `dist60h` 当作召回网**：它提高「名单内命中率」，但缩小「名单轮换到的币数」。
正确用法是**与候选卡 A 组合**：

- **候选卡 A** 决定「看多少个」（召回网，按 `score_total` 前 N）；
- **候选卡 B** 决定「名单内先看谁」（`dist60h` / `combo3` 优先）。

两者组合后：每天仍看 ~70 个（N=20），但**优先层**（`combo3` 前 10）每日去重中位仅 **14** 个，
且这一层在复核段的 10× 命中率是基准的 **3.95×**。

## 5. 验收标准

1. 在**后段（2025–2026）**复核 lift 不塌（≥1.5×）。
2. 同时报告 **lift 与召回**，不得只报其一。
3. 检查「深跌币」的**极端回撤与退市/下架比例**（`dist60h` 升序 = 越跌越买，与「活下来」目标有张力）。
4. 只做对照输出，**不改**生产评分与门槛；未经批准不进入生产。

## 6. 本卡**不**声称什么

- 不声称 `dist60h` 升序是「抄底信号」——本卡只测「排序是否携带信息」，**不测买卖点**。
- 不声称能提高绝对收益或胜率；lift 1.6×–2.1× 是**弱信号**，且基准命中率本身只有 12.14%。
- 不声称 `combo3` 已稳定——它在训练段的 10× 只有 1.17×。
- 未做交易成本、滑点、流动性与可成交性检验。
