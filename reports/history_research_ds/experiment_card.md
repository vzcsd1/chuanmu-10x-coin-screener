**决策小时定义**：决策时刻 `H` = 整点。评分输入 = 开仓时间 `< H` 的已闭合 1h K 线，
按已验收接入补 1 根「进行中」占位尾行（生产 `box_score` 读 `iloc[-2]`）。
决策小时的活跃区间 = `[max(主时段起点, 首根 K 线闭合时刻), min(主时段终点, 末根 K 线闭合时刻)]`；
区间外记为 **not_observable**（不是「未入选」）。

## 3. 时钟、参考价与延迟

- 全部 UTC。
- 发布延迟：**比较 lag=0 与 lag=1 小时两种假设**；两者都只是**假设情景**，不是已证实的取得时间。
  主结果用 **lag=0**，lag=1 作敏感性附页。
- 价格参考（事件/后果）：一律在**信号实际可用之后**取价。
  - 事件识别基准 `m(t)`：第 t 根 1h K 线**收盘时刻**之后 `[t+1, t+720]` 内最高价 ÷ `close_t`。
    **本根盘中高点发生在收盘前，不计入未来**（沿用 `reports/b4_bidirectional_experiment_card_glm.md` 第 7.2 条冻结口径）。
  - 信号后果的参考价：**入选小时 H 的采用 K 线收盘价**（= 归档中唯一可得的粒度），
    标注为「1h 收盘近似」，**不冒充成交价**；仅 5m 覆盖时段不参与本轮主结果。
    - **[2026-10-10 追加]** 上述「1h 收盘近似」保留为**底账内联**口径（`signals/*.jsonl` 的 `fwd` 字段）。
      任务书 §3.3 要求「5 分钟与仅小时覆盖**分组**」，故另设 `forward` 结果组：
      参考价 = **信号可用之后第一根完整 K 线的开盘价**；有 5m 归档用 5m，否则回退下一根 1h 开盘，
      **按粒度分组标注、不混称同精度**。两组各自成表，`forward_*` 不与底账内联口径混用。
      实测：本批 754 个 USDT 现货对象中 5m 覆盖与 1h **完全一致**，723,696 个可测片段
      **全部**落在 5m 组，1h 回退组为空——即本轮不存在「仅小时覆盖」的片段。
- 查询栅格：小时格（底层）；2/3/6 小时固定栅格作为**敏感性对照**（自 00:00 UTC 等间隔），
  不作为主结果。

## 4. 独立事件库（不依赖评分）

- 输入只有现货 1h 的 high/close；**评分函数接触不到事件表**。
- `m_W(t) = max(high[t+1 .. t+W]) / close_t`，W ∈ {168(7d), 720(30d), 2160(90d)}。
- **主窗口 W=720（30 天）**；7/90 天为补充。
- in-wave 集合 `Wset = {t : m_720(t) >= 2}`；连续游程成段；**两段间隔 ≤48h 并入同一事件**
  （48h 为待验证研究设置，另报「不设间隔」敏感性）。
- 事件字段：`start_utc`（第一段首小时）、`end_utc`、`max_m30`、`max_m7`、`max_m90`、
  档位（2 / 2.5 / 3 / 5 / 10，取达到的最高档）、`peak_utc`、段数、`mature`（末段前向窗是否走满）。
- **未走满 30 天 → 未到期（unknown_maturity），不算失败**；无后续数据 → 未知。
- 中途信号（信号晚于事件起点）：照实记录**剩余机会** = 信号小时之后至事件窗内最高价 ÷ 信号参考价。
- 重复：原始逐时点信号全部留存；**机会覆盖按合并事件计**，另报币种数与时间段数。

## 5. 对照与排序

- 同一可比较范围、时间、质量、参考价、窗口下比较：
  1. **当前评分**（`score_total` 降序）
  2. **简单趋势基线**（`c_trend` 单条件）
  3. **3 个固定随机种子**（`20261009 + i`，i=0/1/2）
- **排序并列**：按 symbol 字典序升序。
- **不先定 N**：输出**从首位到全池**的完整关注数量曲线；原版 100%/95%/90%/80% 已捕捉事件
  所需关注数只是**阅读刻度**，不是获批漏选容忍线。
  - **[2026-10-10 追加]** 保留刻度**反算**落在 `retention_lag{0,1}.json`（`retention` 子命令）。
    定义：原版「已捕捉事件」= 事件起点前 30 天窗口内**至少入选过一小时**；
    `covered[n]` = 已捕捉事件中最好名次 ≤ n 的事件数；`required_n` = 使 `covered[n] ≥ 保留比例×已捕捉数`
    的最小 n。**够不到就如实写 `unreachable_within_max_rank=true`，不放大**。
    同文件另报 `reminders_per_event_30d`（重复提醒次数）与 `episode_occupancy_hours/days`（片段占用时间），
    对应任务书 §4 第 3 组「重复提醒及占用时间」。
- 门槛 4/5/6/8/10 只作敏感性并列展示，**不选优、不据此改门槛**。
- **不能先筛掉低分对象再冒充全范围排名**：排序分母 = 该小时**全部可评分对象**。

## 6. 分母与去向（每时点保存）

每个 (对象, 决策小时) 记录：
`status ∈ {selected, scored_below_threshold, skipped:kline_short_history, skipped:kline_gap,
skipped:no_kline_data, not_observable}`，以及 `score_kline / score_deriv / score_total`
（未评分时**记 unknown 而不是 0**）。

- 反向事件去向五类：**不可观察 / 范围过滤 / 缺资料 / 低分或排名靠后 / 出现过晚**。
  - 「范围过滤」：历史市值不可重建 → 标 **unknown**；另用**归档可证的 24h 报价成交额近似**
    （`Σ close_i × volume_i`，最近 24 根）做**显式标注的敏感性**，不当历史闸门。
  - 「低分或排名靠后」分开：门槛未达 vs 达到门槛但排序在 N 之外。
- 数据缺失与停机**不当作行情自然结束**。
- 价格完整但合约缺失的币**不从赢家分母消失**。
- **[2026-10-10 追加]** `forward` 结果组的去向必须**对账**：
  `reach_2x + reach_1_5x_only + below_1_5x + no_reference = 片段总数`。
  `no_reference` = 该片段之后归档里**再无任何 K 线**（只可能发生在对象的最后一个决策小时：
  决策格比已闭合 K 线多一根占位尾行），属**无后续可观察**，
  **不计入上涨/未涨、不当失败**；它使对账成立，取代此前的静默丢弃。
