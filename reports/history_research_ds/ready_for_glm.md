|---|---|
| 标签 `E[j,h]` | 对象 j 在 `[h+1, h+720]` 内有事件起点（档位 ≥ 目标）则为 1 |
| 基准 | 该小时全部**可评分**对象上 `E` 的均值 |
| 命中率 P@N | 该小时按排序取前 N（并列按 symbol 升序）的 `E` 均值，再对小时数取平均（**分母 = 小时数 × N**） |
| lift | 命中率 ÷ 基准 |
| 召回（曾进入前 N） | 事件 j 在 `[start−720, start−1]` 内名次最小值 ≤ N |
| 临门一脚 | `rank[start−1] ≤ N` |
| `dist60h` | `close_t / max(high[t−1439..t]) − 1`（因果，含当根） |
| `ret30d` / `ret7d` | `close_t / close[t−720] − 1` / `close_t / close[t−168] − 1` |
| `boxwidth` | `(max(high[t−167..t]) − min(low[t−167..t])) / mean(close[t−167..t])` |
| `volratio` | `volume_t / mean(volume[t−167..t])` |
| `qv24` | `Σ_{i=t−23..t} close_i × volume_i` |
| `combo3` | `dist60h`（升）、`ret30d`（升）、`boxwidth`（降）逐小时分位归一后**等权平均** |
| 每日去重名单规模 | 按日 24 小时取 `rank ≤ N` 的并集，去重后的对象数 |

**v3 新增口径（`forward` / `retention`）**

| 名称 | 定义 |
|---|---|
| 片段（episode） | 连续选中小时的游程；`signals/lag0/*.jsonl` 一行 = 一个片段 |
| 参考价 | 信号可用后第一根完整 K 线（`open_time >= 片段起点小时`）的**开盘价**；有 5m 用 5m，否则回退下一根 1h |
| 未来 | **严格在参考 K 线之后**的 K 线；参考根自己的盘中高点**不计入** |
| `max_touch` / `max_close` | 窗内最高**价** ÷ 参考价 / 窗内最高**收盘** ÷ 参考价（分开报，不混称） |
| `max_dd` | 窗内最低**收盘** ÷ 参考价 − 1 |
| `mature` | 参考根之后是否走满该窗小时数；未走满记 `immature`（**未到期，不算失败**） |
| `wait_hours_to_Mx` | 参考根之后首次 `high >= 参考价 × M` 的小时数（只在 30 天主窗内判定） |
| `dd_before_2x` | 首次触及 2× 之前，收盘序列相对滚动高点的最大回撤 |
| `no_reference` | 片段之后归档再无任何 K 线 → 无后续可观察；使去向对账成立 |
| `covered[n]` | 已捕捉事件中最好名次 ≤ n 的事件数（名次 = 事件起点前 30 天窗口内最小值） |
| `required_n` | 使 `covered[n] >= ceil(保留比例 × 已捕捉事件数)` 的最小 n；够不到写 `null` + `unreachable_within_max_rank=true` |
| `reminders_per_event_30d` | 该事件起点前 30 天窗口内，该对象被选中的片段数 |
| `episode_occupancy_hours` | 单个片段的持续小时数 |
