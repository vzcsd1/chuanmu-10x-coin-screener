## 2. 瓶颈假设树（交付 2）

四组独立定位的交集与分歧。**共识区**（三组以上独立指向）：**D 排序**（评分与行情幅度脱钩：十倍组中位分 5 低于全体爆拉 6）、**B 时间**（单日快照 vs 真实连续决策）、**H 持有/兑现**（完全空白）、**G 观察**（无连续留痕，H 研究无素材）。**次共识**：J 研究治理（D/E 与 G/H 组押此为第一瓶颈）。**分歧区**：A 发现范围——本轮三组认为闸门已把「看不见」压到次要（成交额上限漏 0% 十倍），但 space-bunny 轮押「选池在前」为第一瓶颈（见其报告 §1），**列为待裁定分歧**，判决依赖 A1 底账的全市场覆盖核算。

| 环节 | 证据一句话 | 当前判断 |
|---|---|---|
| A 发现 | 闸门漏损已量化且小；65.8% 爆拉事件无合约数据是残留缺口 | 次位（有分歧，见上） |
| B 时间 | pre_day 是事后标签；事件定义重合率 0.24~0.42；信号逐年衰减 | **主瓶颈** |
| C 过滤 | 门槛 4→3 只多 2 条爆拉，边际收益低 | 不是瓶颈 |
| D 排序 | 排序键=分数+成交额，并列多、与涨幅脱钩；「71 币过多」实为排序无信任度 | **主瓶颈** |
| E 表达 | 单时点快照丢掉顺序、速度、持续性（四组共识：「数据已存在但没人算」） | 与 D 同根 |
| F 机制 | OI 价值含价格成分；多空比三口径混用过；催化剂独占解释已撤回 | 有缺口，研究卡可补 |
| G 观察 | B10 未实现；历史扫描无配置快照 | **支撑瓶颈**（H/J 的共同前置） |
| H 持有 | 无任何已验证退出规则；468 例峰后深回撤是「拿不住」现象 | **主瓶颈** |
| I 研究 | 探索/确认不分、测试期复用 | 执行层，DE-9/GH-8 治理 |
| J 效率 | 无试验账本，每次优化从头来 | **结构性瓶颈**（DE/GH 押第一） |
| K 目标 | 工作定义已校正，但评估指标（精确率/区分度）与凸性收益结构错配（A/C 组命名为 L「收益结构错配」） | 方向性风险 |
| 新增 M | 字段发布延迟未取证——一切「当时可得」声明的地基 | 全体卡的前置审计项 |
| 新增 N | 对抗性：信号可被低成本伪造、公开规则会被学习（衰减实测） | 未定价的真实风险 |

**结论：不是单一根因，是「B/G/H 咬合 + J 治理缺失 + K 指标错配」的三重相互作用。** 统一解释（待检验）：没有「当时可知的连续决策底账」（G），所以 H 无素材、J 无考场——若 A1 底账冻结后 H 研究仍无进展，此统一解释作废。

## 12. 三个最终问题（任务书必答）

**Q1：只能改变一项核心能力，查什么？**
**「对同一机会随新信息持续判断」的能力（G 环：连续决策底账+状态跟踪）。** 理由：它是 H（持有）、J（研究效率）、B（时间）三环的共同前置——没有它，持有研究只能事后复盘、实验没有考场、时点之争没有裁判。gpt6astra 同轮独立得出同一结论（见其 synthesis §1），两模型收敛但不算独立证据，仅作参考。 runner-up：OI 口径地基（DE-1），因为它最便宜且判决面最大。

**Q2：哪些被忽略的方向最可能改变上限？**
① **确认点剩余空间的测量**（AC-7/CB-2）——它可能把整个项目从「事前预测」改写为「最快确认+持有」，这是定位级变化；② **卖出侧可成交性**（E 类真空）——多倍利润可能卡在「峰值时没人接盘」而不是「拿不住」，全场只有 AC-10 碰了半边；③ **体制识别**（GH-10）——若多倍行情按叙事抱团，「现在是什么体制」比「哪个币」更接近上限。

**Q3：尚未意识到、但弄清后可能改变方向的问题？**
① **字段发布延迟**：所有卡的「只用当时可得数据」声明建立在一个从未取证的假设上（metrics 几点发布？5m 行何时进 ZIP？）——若延迟比想象大，全部历史研究的时间口径要重签；② **信号可被伪造**：对高集中度筹码的庄家，「OI 连增+价格横盘」的蓄势形态可以低成本做出来——若伪造普遍，族 3/族 4 的早证信号价值要重估；③ **统计功效**：24 个十倍样本撑不起委员会想要的细颗粒度结论——可能必须在「答案粗但真」和「答案细但假」之间做痛苦的路线选择。
