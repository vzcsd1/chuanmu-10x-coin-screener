## 0. 说人话（先看这个）

**一句话**：这个项目已经有七轮头脑风暴、两百多条假设、**零个实验**。本轮不再是想"再加哪些指标"，而是回答一个更前置的问题——**尺子和尺子之外的整套测量语言本身是不是错的**，以及**这个项目真正该优化的量是"预测准"还是"少浪费机会"**。

**三条本轮独有的主张**（前七轮都没这么说过）：

1. **统一尺子：把所有预测力换算成"比特（bit）"。** 现在项目有 AUC、命中率、精确率、lift 四种尺子互相不能比较，所以"加一个新指标到底加了多少"永远说不清。互信息能给出统一单位，还能算出"这个特征最多还能贡献多少 bit"——**这决定了值不值得继续加特征**。
2. **把"发现"从预测问题改写成停止问题。** 多倍币不是"看一眼就能判断"的，它需要看一阵子。最优停止理论（optimal stopping）说的是"什么时候该行动、什么时候该放弃"，这天然把"提前量 vs 假信号"这对矛盾变成一个决策，而不是两个互相打架的指标。**项目现在没有任何一层在处理"放弃"这件事。**
3. **研究的自反性：最有效的特征，往往是最容易被榨干的特征。** 项目已实测核心信号区分度从 2024 到 2026 趋近于 0。常见解释是"市场变了"；本轮给出一个同样成立、甚至更可能成立的解释——**这个模式被太多人研究过，alpha 已经被套利掉了**。推论很硬：**继续深挖 OI / EMA / 箱体是在挖一座已经挖空的金矿，应该转向"低研究密度"的区域**（一级市场披露、交易所规则细节、做市商库存、链条上不可伪造的行为痕迹）。

**为什么现在说这个**：项目已经攒了 200+ 条假设，再加 30 条的边际价值接近零。真正稀缺的是**判死的尺子**和**减少发散**。本轮的重点不是数量，是给前面两百条假设提供一个统一的"这个值多少 bit、能不能判死"的框架。

## 3. 瓶颈假设树（本轮版 · 五类并列为候选，未裁定）

前七轮提过 A–K（原始任务书）、L/M/N（表征层 / 瓶颈未测 / 目标-反馈断环 qwen3.8f）。本轮补两个**不同层级**的：

### 3.1 新增类 O · **度量不可通约**（本轮最重）

**主张**：项目有四种尺子（AUC / 命中率 / 精确率 / lift），它们互相不能换算，也都不回答"值不值得"。后果有三：

1. **无法回答"加一个特征值多少"**——只能看到"AUC 涨了 0.02"，无法判断这 0.02 是 0.3 bit 还是 0.003 bit。
2. **无法回答"组合两个特征是不是浪费"**——加权和看不出哪两项在测同一件事。
3. **无法回答"离天花板还有多远"**——如果现有六项已经携带了绝大部分可提取信息，那么第七项的期望收益必然很小，而项目目前没有任何依据知道这一点。

**这个瓶颈比"选池/排序/持有"更前置**：尺子不对，后面每一条实验结论的可信度都要打折（mimo-v2.6pro 轮主张"度量链优先"与本类相邻但不同——mimo 说的是**标签与对照**，本轮说的是**指标之间的单位不统一**。两者可叠加，不互斥）。

### 3.2 新增类 P · **"放弃"这个动作不存在**

**主张**：项目只有"入选"和"没入选"，以及"失效"（在持有语境里）。但真实盯盘里最耗人的动作是：**一个候选进了池子之后，你要决定「继续看它 / 扔掉它 / 等更久」**。这个决策在项目里没有形式，没有成本，没有优化。后果：

- 候选池宽度压力来自"发现太宽"，但如果有了"放弃"层，宽池未必是负担。
- "提前量"与"假信号率"目前是两个互相打架的指标，**因为没有一个决策把两者合并**。
- 用户的真实注意力成本被系统性地低估（项目只有"看几个"的粗口径）。

### 3.3 本轮版瓶颈树（并列五类，投票无效）

```
                    ┌─ O 度量不可通约（无 bit 换算，无法判断增量与天花板）  ← 本轮
                    │
   多倍币捕捉上限 ───┼─ P "放弃"动作不存在（无停止/续观/弃权决策层）    ← 本轮
                    │
                    ├─ L 表征层（三环共用的底层表示）（qwen3.8f）
                    ├─ M 瓶颈定位本身未被测量（qwen3.8f）
                    └─ A–K 原始 A~K（机会发现 / 时间 / 过滤 / 排序 / 信息表达 /
                       机制理解 / 观察 / 持有 / 研究 / 研究效率 / 目标错置）
```

**本轮立场**：O 与 P 是**元层**，它们决定其余十八条假设的结论能不能被信任。**但我不主张"必须先修 O 才能做别的实验"**——相反，我认为 O 可以在一次实验里顺便算（§7 的最小实验设计里已内嵌）。

### 4.2 第二轮 · 相互启发（四处跨组共振）

1. **D 组"消耗存量" × E 组"最优停止"= 新的度量单位**：如果行情是消耗存量，那么**存量的初始值就是先验概率**，"这个币最多能走多远"在启动前就有一个上界估计。这是一个不需要新数据源、可算的量。
2. **C 组"制度披露滞后" × A 组"日历型催化剂"**：前七轮把催化剂研究放在"新闻/社交"，本轮把它移到"**披露文件的发布时间表**"——它是可日历化的、低成本的、有确定提前量的。
3. **G 组"信号检测论" × P 类瓶颈**：固定注意力预算下，"看 N 个"这个约束把问题变成**在 N 次观察里最大化真阳性**。数学上最优解是似然比排序，不是分数排序。这**不是修 bug，是换目标函数**。
4. **H 组"自反性" × 各组共同盲区**：七轮全部把"区分度衰减"归因于"市场结构变化"，**没有一轮问"是不是我们自己把它榨干了"**。这是全场最大的共同盲区。

## 6. 策略突破假设库（30 张 · minimax-m3 · 状态全部为待验证）

> 八字段：①核心假设与机制 ②挑战/改进什么 ③与已有方案关系 ④能否改变上限 ⑤所需数据 ⑥最低成本验证 ⑦什么会推翻它 ⑧失败后留下什么

### 族 M · 度量单位（可通约的尺子）

**MX3-01 比特尺：把所有预测力换算成 bit**
①机制：把每条候选规则对"未来会不会走出多倍"的互信息 I(特征; 事件) 用比特计量。这样"加了什么"变成一道加法题。②挑战"四种尺子各说各话"。③关系：mimo 的 G-1/G-2 修的是标签与对照，本卡修的是**指标之间的单位**。④上限：**高**——它能直接判死一批"加特征"类假设。⑤数据：`backtest_scores.csv` + r3 底账，零新增。⑥验证：算六个现有条件各自的 I 与联合 I（全选 vs 逐个加），画"累计 bit 曲线"，看第几项之后曲线走平。⑦推翻形态：估计方差过大（bootstrap 置信区间 >10%）导致结论不可用 → 那就只用它判冗余、不用绝对值。⑧失败留下：一张"该特征最多还能贡献多少 bit"的上限表，比任何单点区分度数字都更能指导后续投入。

**MX3-02 信号检测论：命中率和误报率不是两个独立指标**
①机制：每天只能深看 N 个，这是**观察预算固定**的检验问题。固定预算下，最优排序是似然比，不是分数。②挑战"先定分数门槛再截断"这个顺序。③关系：与 mimo M25「名额市场」、kx-D1「只配速」同族，本卡给统计形式。④上限：中高。⑤数据：零新增。⑥验证：离线模拟名额 N=3/5/10，比较"分数排序"与"校准概率排序"的赢家覆盖。⑦推翻形态：两者在所有名额下无差异 → 校准不是瓶颈，别再折腾。⑧失败留下：名额-覆盖率曲线（这本身是用户决策工具）。

**MX3-03 序贯检验：允许"看几小时就放弃"**
①机制：用序贯似然比（CUSUM / GLR）给每个候选一条**动态边界**——不是"够不够分"，而是"到目前为止证据够不够、继续看的边际价值是正还是负"。这让"提前量 vs 假信号"从两个打架的指标变成一个决策。②挑战"横截面打分"的整个表示。③关系：qwen3.8f QF-E1（变化点）同族但目的不同——变化点问"数据是否可比"，序贯检验问"该不该继续看"。④上限：**高**（对应新增瓶颈 P）。⑤数据：零新增，小时线已全。⑥验证：对历史波段做回放式序贯，看"停在 t"与"立即进/固定等 N 天"三臂的收益与假信号率。⑦推翻形态：序贯停止在样本外不优于固定等待 → "放弃"层不成立，池子宽就必须靠别的办法压。⑧失败留下：一套候选的"证据轨迹"记录格式，可复用于人工盯盘。

**MX3-04 分母工程：把条件概率连区间一起报**
①机制：现在所有"命中率"的分母都是设计出来的（58.63%）。真实条件概率必须随时间、随池子变化，且必须带置信区间。②挑战"一个数字讲一件事"。③关系：gemini G-2 是其简化版（同日横截面对照），本卡要求**全部**结果都带区间。④上限：中高（不提高上限，但防止自欺）。⑤数据：零新增。⑥验证：对现有 6 个区分度数字统一加 Wilson 区间，看有几个的区间跨零。⑦推翻形态：区间都很窄且结论不变 → 现有结论比想象的稳。⑧失败留下：一份"带区间的结论表"，从此报告不再出现裸百分比。

**MX3-05 归因熵：这个特征到底是哪几个特征在替它说话**
①机制：加权和掩盖了冗余。若 I(量增) ≈ I(量增, OI) 说明量增携带的信息 OI 已经含了。归因分析能直接删掉重复计分的项。②挑战"六项各自独立贡献"的隐含假设。③关系：与 MX3-01 配套；可与 G-6 残差 K 线同时做。④上限：中。⑤数据：零新增。⑥验证：六项两两/三三条件互信息矩阵。⑦推翻形态：矩阵接近对角（无冗余）→ 保留全部。⑧失败留下：一张特征冗余矩阵。

### 族 S · 停止问题（把"犹豫"形式化）

**MX3-06 最优停止：这个项目的主要对象应该是"何时行动"，不是"会不会涨"**
①机制：理论对象是：观察一串信号，随机时刻可停止，停止即执行，收益 = 收益 − 观察成本。项目的六项打分回答的是"是什么"，没回答"何时"。②挑战整个评分导向。③关系：前七轮无人碰这个形式。④上限：**极高**（是范式级）。⑤数据：小时线 + 波段标签，零新增。⑥验证：历史波段回放，比较三种入场（立即 / 固定等 N 天 / 序贯停）。⑦推翻形态：序贯停不优于固定等待且规则不简洁 → 只保留"放弃"这个概念不保留数学形式。⑧失败留下：入场时机与"信号成熟度"关系的一张经验表。

**MX3-07 观察成本计价：用户每看一次都在花钱**
①机制：把每次查看记成成本（时间 + 注意力残留），让它与预期收益一起进目标函数。这样"多扫几个候选"就有了价格。②挑战"名单越短越好/越长越好"的循环争论。③关系：kx-D1（不预测只配速）的量化版。④上限：中高。⑤数据：需人工记录查看次数（新流程）。⑥验证：连续 4 周记录每次查看的耗时与后续决策价值。⑦推翻形态：查看成本小到可忽略 → 直接放弃这条。⑧失败留下：一份真实的注意力成本台账（项目至今没有任何一个真实用户行为数据）。

**MX3-08 再入场是独立决策，不是补丁**
①机制：错过首启后的第二次参与，其信息集、风险、目标函数都与第一次不同，不该用同一套规则。②挑战"持有规则统一适用"。③关系：与 GLM H12、mimo M23 同向，本卡强调**独立策略身份 + 独立验收标准**。④上限：中高。⑤数据：r3 底账路径。⑥验证：第二段参与的胜率/赔率单独统计。⑦推翻形态：第二段无统计优势 → 二次上车整族降级。⑧失败留下：接力段样本库。

### 族 E · 能量与存量（把涨幅翻译成消耗）

**MX3-09 能量预算：一次十倍行情消耗了什么**
①机制：价格不会无中生有地上涨，它必然消耗某种存量：可轧的空头燃料、可被换手的自由筹码、或传播所需的注意力。**问"哪一个存量先耗尽"比问"会不会涨"更接近机制**。②挑战"用价格指标推断供需"的间接做法。③关系：与 D 组 OI 四象限（space-bunny D-4）相邻但层级更高——D-4 查瞬时方向，本卡查**存量耗尽曲线**。④上限：**高**。⑤数据：零新增（OI 存量、成交量历史、流通盘可得）。⑥验证：对 24 个十倍事件算三条耗尽曲线（空头燃料/OI、自由筹码/累计换手、注意力/成交额持续时间），看哪条在启动前就已接近耗尽。⑦推翻形态：三条曲线与后续涨幅均无关联 → 存量框架不成立，砍掉整族。⑧失败留下：三个"耗尽度"指标的构造方法。

**MX3-10 拥挤度机会成本：叙事里第 4 个涨的币最危险**
①机制：同一个叙事内，第 1、2 个币吸走资金，第 4 个接手的是**剩余注意力**。构造"同叙事已在涨的币数 / 该叙事总币数"，作为减分项。②挑战"逐币独立评分"。③关系：与 M19 传导网络同族，本卡是负向版本。④上限：中。⑤数据：需要叙事聚类（可用价格相关性替代粗版本）。⑥验证：同叙事内序号 vs 后续涨幅。⑦推翻形态：无单调性 → 拥挤度不构成约束。⑧失败留下：叙事簇粗聚类方法。

**MX3-11 生态位轮替：机会在生态位之间轮转**
①机制：不是某个币一直好，而是"某个生态位"轮流爆发（ meme → 铭文 → AI → RWA …）。捕捉多倍币的部分工作是**判断当前该盯哪个生态位**，而不是在固定池子里排。②挑战"候选池 = 全市场扫描"。③关系：与 mimo M29 世代地图同向，本卡要求生态位**可操作**（先得能分簇）。④上限：中高。⑤数据：零新增（价格相关性粗聚类可用）。⑥验证：粗聚类下，同簇内是否存在显著的事件时间聚集。⑦推翻形态：事件时间在簇间均匀 → 没有轮替，退回随机扫描。⑧失败留下：一份价格相关性簇结构。

### 族 R · 制度与外部性（本轮主打的新区）

**MX3-12 制度资金的信息滞后：最有价值的提前量可能来自披露文件**
①机制：ETF 每日持仓、上市公司季报持仓、做市商牌照与库存披露——这些有**确定发布时间**，且内容早于价格。信息不是价格，是披露。②挑战"提前量只能来自盘面"。③关系：B3 催化剂识别的对象不同（B3 是新闻公告，本卡是**持仓披露文件**）。④上限：**高，且成本极低**（数据公开、可日历化）。⑤数据：公开披露文件。⑥验证：抽 50 个历史十倍币，查启动前 90 天内是否出现在任一披露文件中；命中率作门槛。⑦推翻形态：命中率 <10%（山寨币基本不在披露里）→ 直接判死，零成本止损。⑧失败留下：一份"披露源对山寨币的覆盖地图"，避免下一轮再花时间。

**MX3-13 规则变更作为结构断点**
①机制：交易所规则、指数成分调整、结算机制、资金费率上限——**规则的微小改动会触发一次性重新定价**。这类事件有确定日期、可提前准备、几乎无人研究。②挑战"事件都是自发的"。③关系：mimo M09（上所阶梯）的邻近族。④上限：中。⑤数据：交易所公告归档（公开）。⑥验证：把历史上若干规则变更日前后 ±30 天做事件研究。⑦推翻形态：变更前后无系统差异 → 规则断点不存在。⑧失败留下：一份历史规则变更日历。

**MX3-14 一级市场：打新、迁移、rebase 的信息优势**
①机制：上所前的社区募资、空投、跨链迁移、代币重命名——这些是一级市场，**信息优势远大于二级**。项目的观察池从上市后才开始，等于放弃了上游。②挑战"扫描范围就是全部机会"。③关系：与 space-bunny 的"选池在前"同向，但对象是**一级市场**而非小市值二级池。④上限：中高。⑤数据：需要一级市场数据（新来源，成本待评估）。⑥验证：先做零成本版——查历史十倍币的上线前社区数据是否存在可回溯痕迹。⑦推翻形态：一级市场痕迹与二级表现无关联 → 放弃。⑧失败留下：一级市场可得性清单（哪些能拿到、哪些拿不到）。

### 族 X · 自反性（元层，本轮最重）

**MX3-15 研究自反性：越被研究的信号越先失效**
①机制：一个公开模式被足够多人研究后，alpha 被套利掉。项目的六项权重全部来自 841 个事件的公开复盘——**它们是"已经被研究透的领域"的代表**。区分度逐年衰减至少有一个原因是"被榨干"，而不只是"市场变了"。②挑战**前七轮的整个重心**。③关系：对 A0/A3/A4/A6/A7 的排序前提提出质疑。④上限：**极高**（若成立，研究方向需重排）。⑤数据：零新增（需研究密度代理指标）。⑥验证：把每个特征按社区研究密度分级，看**衰减幅度与研究密度的相关性**；若不相关则本卡被削弱。⑦推翻形态：密度与衰减无关 → 自反性不成立，本卡的推论全部作废。⑧失败留下：一张"主题研究密度—信号衰减"图，本身就是研究资源分配的依据。

**MX3-16 观察者效应扣除：我们自己也在改变对象**
①机制：对小币来说，"被很多系统盯上"本身就是价格支撑。当研究者的关注构成需求时，被广泛研究的币的启动会被推早。含义：**用"被研究次数多"的样本评估策略会系统性乐观**。②挑战"历史事件库是自然样本"。③关系：与 H 组对抗组、mimo M13 操纵指纹同族。④上限：中（是方法论约束，不是新信号）。⑤数据：零新增（需要"被多少系统覆盖"的可得代理，如是否进过多份榜单）。⑥验证：比较"被多份公开榜单收录"的币 vs 未收录的币的启动时间分布。⑦推翻形态：无差异 → 观察者效应可忽略。⑧失败留下：样本分层清单。

### 族 C · 认知与呈现（人的那一端）

**MX3-17 反事实清单：告诉用户"今天为什么不是另外 10 个"**
①机制：现在的输出是"选中了什么"。漏报是不可见的，而漏报才是伤害。把当日**头部被排除者 + 排除理由**一并展示，漏报从"不知道"变成"可辩论"。②挑战"名单就是产品"。③关系：与 mimo MD05 双池、KD10 证伪清单同族。④上限：中高（直接改善盯盘体验与研究反馈）。⑤数据：零新增（现有扫描结果即可）。⑥验证：连续 4 周记录"被反事实清单纠正过的判断"次数。⑦推翻形态：几乎从不改变判断 → 降级为可选展示。⑧失败留下：一个高价值的 UX 改动。

**MX3-18 案例可读性优先于分数：给三个最像的历史案例**
①机制：不输出"8.3 分"，输出"最像它的三个历史案例，及其启动后完整路径"。人擅长案例判断，不擅长分数判断。②挑战"分数是决策依据"。③关系：与 E-3 相似行情检索相邻（那卡是给规则用，本卡是给**人**用）。④上限：中高。⑤数据：零新增。⑥验证：盲测——给 20 个候选，比较"分数"与"三个案例"两种呈现下的人工判断与后续实际走势的一致度。⑦推翻形态：案例呈现不优于分数 → 人更信分数（这本身是有价值的负面结论）。⑧失败留下：案例检索层 + 一次盲测结论。

**MX3-19 零知识模式：不做预测，只建证据档案**
①机制：把产品定位为"每个候选的完整证据档案 + 失效条件清单"，不做任何涨跌判断。反驳"必须输出概率/分数"。②挑战"筛选器必须给答案"。③关系：kx-D2、mimo MD10 同向，本卡最彻底。④上限：未知（可能很高也可能不适配用户）。⑤数据：零新增。⑥验证：纸面原型——手工为 10 个候选做证据档案，看是否比现有分数更快做出决策。⑦推翻形态：档案制明显更慢更累 → 放弃。⑧失败留下：一份"证据档案"模板。

### 族 T · 时间与环境（结构层）

**MX3-20 选时可能比选币更重要：全局开关**
①机制：如果多倍币的出现有**市场层面的窗口**（如波动率结构、资金环境），那么"今天该不该看山寨"这个开关可能比"看哪个山寨"更值钱。横截面上币的差异，可能小于时间上的差异。②挑战"逐币评分是主结构"。③关系：space-bunny C-5 时段效应、mimo M29 世代地图的同族，本卡要求**开关先于扫描**。④上限：高。⑤数据：零新增。⑥验证：按周/按月统计多倍事件密度与同期波动率/流动性环境的关系；若 R² 低 → 开关不存在。⑦推翻形态：无时间聚集性 → 币间差异确实是主因，维持原结构。⑧失败留下：一张"环境-事件密度"曲线。

**MX3-21 三维解耦：币 × 阶段 × 环境**
①机制：同一个币在不同阶段身份完全不同（沉寂 / 蓄势 / 启动 / 派发）。同一个阶段在不同环境含义不同（牛熊）。现在的六项把三者压成一个数。②挑战"单一分数"。③关系：与 kx-D2 状态化、mimo M16 多尺度同族，本卡强调**三维正交**。④上限：中高。⑤数据：零新增。⑥验证：三维分层后各层内的条件启动率差异。⑦推翻形态：分层后差异不显著 → 单分数够用，砍掉。⑧失败留下：三维分层标签体系。

**MX3-22 临界时刻：最后一个还能买到的时刻**
①机制：对每个赢家，找最后一个"此后价格不再回到该水平"的时点 T\*，标记为临界时刻。研究 T\* 之前发生了什么。**这比"事后高点"更贴近可参与性**，且天然产生提前量指标。②挑战"用高点定义标签"。③关系：与 mimo M06 可参与标签相邻——M06 从**可成交性**切，本卡从**不可逆性**切，两者互补不重复。④上限：**高**。⑤数据：零新增。⑥验证：对 24 个十倍事件算 T\*，看 T\* 与低点的时距分布，以及 T\* 前 24h 的特征是否可提前识别。⑦推翻形态：T\* ≈ 高点且不可提前识别 → 无增量价值。⑧失败留下：临界时刻的标准算法（可复用于未来候选）。

### 族 D · 微观结构新角度

**MX3-23 净换手审计：涨幅的"现金实现"**
①机制：涨幅是账面（类似利润表），真正的收益是**换手实现**（类似现金流量表）：谁在净买入。如果一次十倍过程中净买入集中在少数时点，其余时间是小额换手，说明筹码没有真正转移，后市脆弱。②挑战"用价格 + 成交量就够"。③关系：与 gemini G-4 订单流三件套、space-bunny D-2 taker 占比同族，本卡要求的是**累计净流向的时间分布**而非水平值。④上限：中高。⑤数据：归档库 taker 字段（已下载，覆盖率 724/1402 需注意）。⑥验证：净流入的时间集中度（基尼系数类）vs 后续涨幅。⑦推翻形态：集中度与后续无关 → 订单流整族降级。⑧失败留下：净换手累计曲线。

**MX3-24 熵坍缩：价格变得"过于可预测"**
①机制：正常市场有随机性。当一个币的短期可预测性突然上升（残差熵下降），通常意味着**有人在持续下单**（累积挂单）或**流动性变薄**（更易被推动）。这是"量的变化"的补充，是"可预测性的变化"。②挑战"只测量水平量，不测量随机性变化"。③关系：与 E-4 矩阵画像同族（都是"找没见过的形态"），本卡有明确的理论量。④上限：中。⑤数据：零新增。⑥验证：对历史事件算启动前的条件熵轨迹。⑦推翻形态：熵轨迹无规律 → 放弃。⑧失败留下：熵指标构造法。

### 族 V · 目标函数

**MX3-25 目标函数重构：最大化"净对数增长的期望"**
①机制：万倍（5 年 530%/年）在数学上等价于**少量极高倍数的持续复利**，而不是"提高命中率"。目标函数应写成 E[log(1+倍数×仓位)] − 成本 − 破产惩罚，而非"命中率"。这条把项目的所有指标重排。②挑战"命中率是第一指标"。③关系：与 STRATEGY_REVIEW §1 的用户目标直接对齐，是**目标的数学化**。④上限：**极高**。⑤数据：零新增。⑥验证：把现有所有候选按此目标函数重新排序，看优先级变化有多大。⑦推翻形态：排序结果与现有完全一致 → 无所谓。⑧失败留下：一份正式的目标函数定义。

**MX3-26 分数凯利在厚尾高噪声下会失效**
①机制：凯利公式假设可重复的概率分布。加密右尾极厚、概率估计极不稳，直接用分数凯利会**过度下注**。需要为估计误差加惩罚项。②挑战"用凯利管仓位"。③关系：与 mimo M04 随机对照同族。④上限：中高。⑤数据：零新增。⑥验证：不同估计误差下的模拟仓位曲线对比。⑦推翻形态：加入惩罚后收益无改善 → 惩罚项不必要。⑧失败留下：一份带误差惩罚的仓位表。

**MX3-27 "捕捉次数"应该是一等指标**
①机制：目标是多次捕捉，所以**单位时间内的合格机会数**（而非单次质量）是更贴近目标的一等指标。这会改变实验的评价口径。②挑战"以单次命中率评价实验"。③关系：与 mimo MD11 漏报 KPI 同向。④上限：中高。⑤数据：零新增。⑥验证：把现有实验按新口径重排，看结论是否翻转。⑦推翻形态：新口径下排序不变 → 无所谓。⑧失败留下：双口径评价表。

### 族 B · 记忆与研究资产

**MX3-28 影子评分器：新指标立刻入池，连续 6 个月无增量就毕业或退休**
①机制：维护 N 个影子指标，全部实时计算、全部记录预测结果，季度答辩一次。这样"该不该加指标"从争论变成实验。②挑战"加指标靠讨论决定"。③关系：与 mimo M07 保质期、qx-D7 日落制同向，本卡要求**并行运行而非替换**。④上限：中高。⑥验证：跑两个季度，看有几个影子指标真有过增量。⑦推翻形态：绝大多数影子指标无增量 → 结论是"少加指标"，同样有价值。⑧失败留下：一个永久的指标判决机制（本项目至今没有）。

**MX3-29 负面结果银行：把"死法"正式记录下来**

**MX3-30 墓碑库：把"曾经伟大过"的币建成资产**

## 13. 三个最终问题

### Q1 · 如果只能改变项目的一项核心能力，最值得调查的是什么？

**「让每一条现有结论都能被换算成同一把尺子的 bit，并且知道离天花板还差多少。」**

理由：项目现在有 200+ 条假设、0 个实验、7 轮发散。这不是想法不够，是**没有办法判断哪条想法值多少钱**。四种不可通约的尺子（AUC / 命中率 / 精确率 / lift）让"加一个特征"永远只能得到"AUC 涨了 0.02"这种无法判断大小的回答。互信息尺子直接回答三件事：这个特征值多少 bit、它是不是在重复别人的信息、还剩多少 bit 可以挖。**第三个问题尤其关键——如果天花板已经逼近，那么"加指标"这整族方向（包括前七轮大量卡片）应该立即降级，研究资源转向停止问题与目标函数。** 这是一项能力，不是又一个指标。

### Q2 · 哪些被忽略的方向最可能改变上限？

按我的判断排序：

1. **研究自反性（MX3-15）**——被忽略得最彻底，也最可能改变整个研究方向而非某个局部。如果"区分度衰减"的原因是模式被榨干，那么继续深挖 OI/EMA/箱体就是在挖空的金矿里找金矿，**而前七轮的重心恰好全压在这六个字段上**。
2. **最优停止（MX3-06）**——"什么时候该放弃"这件事在项目里完全不存在，而它恰恰是人工注意力真实消耗的地方。加了它，池子宽度的压力会显著下降。
3. **制度资金的披露滞后（MX3-12）**——唯一一个"提前量来自币外、且有确定日期"的区，被完全忽略。成本极低，可快速证伪。
4. **E[log] 目标函数（MX3-25）**——万倍在数学上是复利次数问题，不是单次命中率问题。当前所有指标可能都在优化错的东西。

### Q3 · 有哪些尚未意识到、但一旦弄清楚就可能显著改变整体研究方向的问题？

1. **"我们测到的区分度，有多少其实是回溯性幻觉？"**（墓碑库 MX3-30 的诊断版）——如果评分对未来的预测力远低于对已发生暴涨的解释力，那么七年积累的核心结论里，可能有相当一部分只是"给已发生的事情编了个理由"。**这个问题一旦有答案，整个知识库的可信度都要重估。**
2. **"如果加指标的期望收益已经接近零，那么前七轮的绝大多数方向都是浪费吗？"**（MX3-01 的天花板版）——这是本轮最刺痛但也最有价值的问题。
3. **"我们的候选池，是不是只在研究'已经被发现过的机会'？"**——赢家都来自上市后已被充分扫描的范围。**真正值钱的可能在上游**：一级市场、上市前的社区、极早期的注意力。这直接对应 space-bunny 押的"选池在前"，但本轮给了一个具体位置。
4. **"如果研究的边际收益递减，那么这个项目的终局是什么？"**——项目已经进入"发散 7 轮、实验 0 轮"的状态。是把现有东西验到能用，还是继续想？这是需要用户判断的策略性问题，不是技术问题。
