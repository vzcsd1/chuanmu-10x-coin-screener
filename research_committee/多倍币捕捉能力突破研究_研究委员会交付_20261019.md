### 1.5 一个被忽略的存量资产

本地 `data/1h/*.parquet`（3,140 个文件）的列是：

```
symbol, open_time, open, high, low, close, volume, close_time,
quote_volume, trades, taker_buy_base, taker_buy_quote, dt
```

`taker_buy_quote` 是**主动买入成交额**，`trades` 是**成交笔数**。两者都能零成本推出三个从未使用的特征：

- 主动买入占比 `taker_buy_quote / quote_volume`（买卖压力方向）
- 平均单笔规模 `quote_volume / trades`（大单/散户结构代理）
- 单位成交额的价格冲击 `|return| / quote_volume`（薄盘程度）

而 `data/backtest_scores.csv` 里已经有一列 `taker`（724 非空），我复算其中位切分区分度是 **+5.8pp**（爆拉组 53.5% vs 对照 47.7%），与"突破箱体"的 +5.7pp 同一量级——**但它从未进入评分，也从未出现在任何一份条件对比表里**。

这不是"建议接新数据源"，而是"数据已经付过费、已经落盘、没人打开看"。它构成本报告 §5 中成本最低的一个实验。

## 2. 瓶颈假设树

### 2.1 先看一个数字：58.6% 与 5.15%

项目所有"精确率"都建立在一个被抬高的基准上。`策略前视与马后炮审计.md` §5 自己写得很清楚：对照组特意从"曾经爆拉过的币"里抽，基准爆拉率被抬到 59~62%，"所有精确率和提升倍数都偏乐观，只能做横向比较"。

现在把它算完：

```
样本基准率        = 822 / 1,402 = 58.6%
门槛 5 的精确率   = 72.3%
提升倍数 (lift)   = 72.3 / 58.6 = 1.234
```

而 A1 r3 在**全底账**上复算出的 30 天 ≥2 倍比例是 **5.15%**（小时观测口径，窗口重叠，不是独立机会率）。

若这个 lift 能迁移：

```
真实条件下入选者的 30 天 ≥2 倍概率 ≈ 5.15% × 1.234 ≈ 6.4%
```

**这就是全部问题的量级**。不是"72% 命中率还能不能提到 80%"，而是"真实命中率可能只有个位数百分比，而项目一直在用 72% 这个数字做决策"。

必须说明这个换算的三个限制：①5.15% 是小时行口径，与"每天选一批币"的分母不同；②lift 是在不同条件下测的，未必可迁移；③底账只覆盖 713 个身份，不是全市场。所以它是**量级提示，不是精确预测**。

但方向是确定的：**在真实分母下，这套系统的价值不体现在"猜得准"，而体现在"把 6% 提到 8%，同时不漏掉那 0.24% 的十倍"**。而后者是长尾，前者是均值。二者需要完全不同的优化方法。

这一条直接决定了本报告的立场：**继续在 58.6% 的样本上做条件筛选，是在优化一个不存在的市场。**

### 2.3 新增三个瓶颈类别

**L. 资格层缺失（物理约束从未建模）**

现有系统只有"评分层"，没有"资格层"。评分回答"这个币现在强不强"，但从不回答"这个币在结构上有没有可能翻数倍"。

证据链是闭合的：
- 十倍组 K 线均分 **4.25**，低于 2–3 倍组的 **5.17**（我独立复算）；
- 十倍组突破箱体命中 **0%**（复盘报告）；
- 24 个十倍事件里 **10 个总分恰好等于 5**（我独立复算），即刚好卡在门槛上；
- 822 个正例里 **541 个（65.8%）**缺完整合约三字段。

四条合起来说明：**评分对最大的赢家几乎没有增量，它们是被"进入池子"这件事捞到的，不是被"分数高"选出来的。** 那么真正的杠杆在资格层（谁能进池），而不在评分层（进来之后排第几）。

**M. 目标函数错置（发现与持有共用一套逻辑）**

系统用一个 `score` 同时承担三件事：发现（要不要看）、排序（先看谁）、持有（要不要留）。这三件事的最优解很可能相反：

- 发现奖励**变化率**（OI 突然加速、量突然放大）；
- 持有奖励**结构未破坏**（趋势仍在、回撤未破关键位）；
- 退出奖励**波动率扩张 + 基差异常**（派发特征）。

用同一个分数做三件事，必然在其中两件上是错的。项目从未把三者分开建模。

**N. 可见性偏差（不是生存偏差，是"当下可见性"偏差）**

研究库含已下架币（ALPACA 45.68x 就在库里），但在线扫描只能看到**当前上市**的标的。于是"下架前最后一拉"这类被复盘报告明确记录的高倍模式，在实盘系统里**结构上不可见**。

这不是"研究错了"，而是"研究与实盘的样本空间不同"，而项目从未把这个差异写进任何结论的适用范围。

### 2.4 瓶颈树的结论

如果把瓶颈画成树：

```
长期资产增长上限
├── 抓到（发现）           ← 资格层 L（未建模）+ 时点 B（定义可疑）
├── 抓对（排序）           ← 目标函数 M + 真实分母 D（从未测）
├── 拿住（持有）           ← 完全空白 H
└── 不亏回去（退出）       ← 完全空白 H
```

**三个分支里，只有"发现"被认真优化过，而它的评估基准是错的（§2.1）；"排序"从未在真实分母下测过；"持有/退出"从未开始。**

所以对"我们是否一直在优化错误的问题"的回答是：**不完全是错的，但优化的是整条链上最不稀缺的那一环。** 在多倍币捕捉里，"看出一个币在涨"是最容易的部分；难的是"它在物理上能不能翻倍""在 400 个候选里它该排第几""涨了 3 倍后要不要留"。项目把 90% 的精力放在了最容易的部分。

## 3. 研究委员会讨论记录

> 说明：以下角色是**方法论的化身**，不是对真人的模拟发言。凡引用真实交易者的观点，均在 §4 单独标注来源与证据等级；本节中的"某组认为"是本报告基于其公开方法所做的机制推演，**不构成对任何真人的引述**。

### 3.1 第一轮：独立发散（8 组，30 条）

规则：每人先只提"最可能改变上限"的想法，不谈实现难度。括号内为初始分歧标记。

**A 组 · 经典交易体系（5 条）**

- **H01 关键点三段式**：多倍行情不是"突破"一个点，而是"压缩 → 首次突破 → 回踩不破"三段。当前 `c_breakout` 只测第二段，缺第一段和第三段。〔A 组主张这是核心，H 组当场反对〕
- **H02 风险单位与金字塔**：把"发现"和"下注"解耦。信号只决定进观察池，浮盈按 ATR 加仓决定收益上限。海龟规则里真正赚钱的是加仓，不是入场。
- **H03 趋势模板当资格层**：用多尺度一致性（价在长均线上、距区间高点近、相对强度靠前）做**准入**，而不是加分项。当前 `c_trend` 是 5 分加分，用错了位置。
- **H04 波动收缩序列（VCP）**：用"回撤幅度递减"（−18% → −9% → −4%）替代"箱体宽度 ≤12%"这个静态量。项目已证伪的是静态宽度，不是收缩过程。
- **H05 波动率退出**：退出用"波动率扩张 + 结构破坏"双条件，而不是固定百分比止盈。项目连一个退出规则都没检验过。

**B 组 · 加密实战（5 条）**

- **H06 跨所合约资格**：币安与 OKX 同时有、且 OKX 有合约，是"庄家可跨所布局"的结构条件。项目已算 OKX 字段、已写 `REQUIRE_OKX`，却从未使用。
- **H07 期现价差（基差）**：现货被拉、合约不跟 → 基差扩张，是控盘/逼空的直接证据。项目同时取了现货和合约 ticker，**从未计算过两者之差**。
- **H08 鱼尾派发**：OI 先骤降再反升 + 基差异常扩大 + 链上提币消失 = 派发。用于"卖出"，不用于"买入"。
- **H09 新永续上线**：小币首次上线永续 = 杠杆接入 + 做市商进场，是外生冲击。用 `load_markets` 快照 diff 即可。
- **H10 二次启动**：首次爆发后回撤 60–80% 并重建结构，是**独立第二类机会**，需要单独标签，不能混进主样本。

**C 组 · 跨市场（5 条）**

- **H11 低流通/高 FDV**：流通市值占总市值比例低 → 拉盘成本低。这是"能不能翻倍"的物理约束，不是统计信号。
- **H12 解锁日历**：大额解锁前 2–4 周的护盘式拉盘、解锁后的派发，是**时间可预知**的事件。
- **H13 空头持有成本**：负资金费率持续 = 空头拥挤度在累积。注意：项目已测"负费率"是噪音，但那是**主效应**；作为交互项从未测过。
- **H14 宏观开关**：BTC 主导率拐点/山寨季决定"今天该不该出手"，属于预算层，不该进个股评分。
- **H15 吸收率**：公告后 1h/4h/24h 的"成交量/涨幅比"，区分真需求与一次性脉冲。

**D 组 · 微观结构（5 条）**

- **H16 OI 数量与价值分离**：现有 OI 是**价值**口径，价格涨本身推高它。用张数变化剔除价格效应，才能得到"真实新增持仓"。
- **H17 主动买卖比**：`taker_buy_quote` 已在本地 parquet，`taker` 列已在 `backtest_scores.csv`，从未入模。我复算中位切分 +5.8pp。
- **H18 平均单笔规模**：`quote_volume / trades`，大单占比上升 = 机构化建仓，散户接盘则相反。
- **H19 薄盘度**：`|return| / quote_volume`，薄盘意味着少量资金即可推动，是"可被拉"的必要条件。
- **H20 清算瀑布**：OI 骤降 + 价格急跌 + 费率极端 → 强平级联。之后的反弹与"洗盘"是两种不同结构，不能混谈。

**E 组 · 量化与算法（5 条）**

- **H21 排序学习替代打分**：目标不是"给每个币打分"，是"给定预算 N 最大化捕获"。用 LambdaRank/NDCG 直接优化排序。
- **H22 条件性有效**：单条件无效 ≠ 组合无效。项目 18 个条件全是**边际**检验，交互项一个没测。
- **H23 变化点检测**：用 CUSUM / 贝叶斯变点找"状态切换时刻"，替代固定窗口差分。`pre_day` 本质是在猜切换点。
- **H24 相似行情检索**：把当前形态映射到历史路径分布（kNN/DTW），输出"未来 30 天收益分位"，而不是二分类。
- **H25 多专家竞争**：趋势专家 / 事件专家 / 挤压专家各自出名单，按近期表现动态加权。承认没有单一最优逻辑。

**F 组 · 社区与田野（4 条）**

- **H26 假阳性解剖**：社区讨论最多的不是"什么会涨"，是"为什么这个看着一样却不涨"。项目只有正例+随机对照，没有"同形态失败"专项。
- **H27 链上净流入**：交易所钱包净流入/巨鲸标签，社区争议大但可证伪。
- **H28 叙事生命周期**：新概念 → 扩散 → 人人皆知的时间尺度，用提及量做代理。
- **H29 做市商指纹**：同一批币的"拉—横—再拉"节奏是否可识别（事件间隔分布、回撤深度分布）。

**G 组 · 跨学科（4 条，收敛为 1 张卡）**

- **H30 注意力预算（检索式排序）**：把每日候选当成搜索结果页，优化"单位注意力捕获的期望收益"，而不是覆盖率。这是把"筛选"重构成"检索 + 预算分配"。

**H 组 · 红队（不新增卡，专门攻击上面 30 条）**

- 攻击 A 组：H01 的"三段式"在 24 个十倍样本里可能根本不成立（突破命中 0%）。
- 攻击 B 组：H06/H07 的机制讲得通，但**没有一条本地证据**，属于"漂亮的因果故事"。
- 攻击 E 组：H21 换目标函数会立刻遇到"没有可靠标签"的问题——现在的标签是事后低点到高点，排序学习会把这个偏差学得更彻底。
- 攻击全组：**你们都在假设"多倍币有共同前兆"。也许真相是：十倍是尾部事件，前兆分布与 2 倍没有本质差别，能做的只有"扩大参与面 + 控制单次损失"。**

**第一轮小结**：30 条里，有本地证据支撑的只有 6 条（H05 部分、H16、H17、H18、H22、H30 部分），其余 24 条是**机制合理但未验证**。这个比例本身说明：项目不缺想法，缺的是"用现有数据两天内能证伪"的想法。

### 3.2 第二轮：相互启发（5 处共振）

**共振 1：A 组的"资格"与 C 组的"供给"是同一件事**
A03（趋势模板当准入）和 C11（低流通）表面无关，实质都是**把评分从"排序"降级为"过滤"**。合并后产生新命题：**先判"能不能"，再判"强不强"，最后判"值不值得现在买"——三层，三个不同的问题。**

**共振 2：B 组的三条（H06/H07/H08）其实是同一个"跨所控盘"机制的不同侧面**
资格（能不能跨所布局）→ 过程（基差扩张）→ 终结（派发）。这构成一个**完整生命周期模型**，而不是三个独立指标。项目现有评分只覆盖"过程"的一小段。

**共振 3：D 组的 H17/H18/H19 全部来自同一份被忽略的数据**
三者都只需 `taker_buy_quote`、`trades`、`quote_volume` 三列。这意味着**一个下午就能把 D 组全部证伪或证实**。E 组当场承认："这是全场性价比最高的实验。"

**共振 4：E 组的 H22（交互）与 C 组的 H13（负费率）指向同一个盲区**
项目测"负费率"主效应得到 −4.4pp（反向），于是移出评分。但 B 组指出：负费率只有在"低流通 + 高 OI/市值"时才意味着挤压燃料。**主效应为负，可能是被"高流通大币的负费率"稀释了。** 这是"用边际检验否定了条件性真理"的典型。

**共振 5：F 组 H26 与 H 组攻击的交汇点**
H 组说"十倍可能没有前兆"，F 组说"社区讨论最多的是为什么不涨"。两者合起来给出一个可执行的研究：**不研究"什么会涨"，研究"什么看起来会涨但不会涨"——因为后者的样本量大 10 倍，且正好是系统每天在误报的那批币。**

**A 组当场提出的反对**："如果十倍没有前兆，那这个项目就没有存在意义。"H 组回应："不是没有前兆，是前兆的**区分度**可能低于你愿意接受的水平。承认这一点，才能从'预测'转向'凸性参与'。"

### 3.3 第三轮：支持方与反方交锋（4 场）

#### 交锋一：十倍币到底能不能提前发现？

- **支持方（A 组 + B 组）**：能。24 个十倍里 19 个在门槛 5 以上，说明它们并非完全无迹可寻；且 18 条件触发时前 7 日涨幅中位 <11%，证明信号是"价格没动就触发"的。
- **反方（H 组）**：不能，至少不比 2 倍更容易。硬证据：十倍组 K 线均分 4.25 < 2–3 倍组 5.17；十倍组突破命中 0%；24 个里 10 个恰好 5 分。如果前兆更强，分数应该更高，而不是更低。
- **第三方验证方案（E 组）**：不看均值，看**分层单调性**。把 822 个正例按 K 线分 0–8 分桶，算每桶内 `gain>=9` 的比例。若"分数越高、十倍占比越高"不成立（甚至反向），则"评分能识别十倍"被证伪。**这个检验 30 分钟可完成，不需要新数据。**
- **裁决**：反方证据更强，但结论应限定为"**现有特征集**对十倍无正向区分"，而不是"十倍不可发现"。差别在于：现有特征全是"状态量"，没有"结构量"（供给、跨所、基差）。

#### 交锋二：评分体系该保留、改造，还是废弃？

- **支持改造（E 组）**：保留特征，换目标函数。用排序学习替代加权求和，因为加权求和隐含"各条件可加且独立"，这与"条件性有效"直接冲突。
- **支持废弃（H 组）**：评分是代理变量的堆叠。`c_trend` 的 +35.3pp 很可能只是"已经在涨"的同义反复——它没有在控制"前期涨幅"后测过残差增量。
- **支持保留（A 组）**：评分至少提供了一个可解释、可人工复核的排序。黑箱排序在只有 24 个十倍样本时必然过拟合。
- **第三方验证方案（D 组）**：做**残差化检验**。以 `ret_30d_pre`（前 30 日涨幅）为控制变量，把 `c_trend` 对 `ret_30d_pre` 做逻辑回归，看 `c_trend` 的系数是否仍显著。若系数塌掉，则趋势分确实是同义反复。**用现有 `features_audit.csv` 即可，1 小时。**
- **裁决**：三种意见可以并存于不同层——资格层用规则（可解释）、排序层用学习（可优化）、持有层用事件（可证伪）。**"一套评分走天下"才是真正该废弃的东西。**

#### 交锋三：候选越少越好吗？

- **支持压缩（F 组 + G 组）**：人工注意力是硬约束。71 个候选没人看得完，等于 0 个。
- **反方（H 组）**：压缩必然杀长尾。收益集中度 51.4% 说明少数极端赢家决定结果，而极端赢家恰恰是最不像"标准候选"的那批。
- **第三方验证方案（G 组）**：不争论数字，画**预算-覆盖曲线**。横轴"每天看几个"，纵轴"保留了多少个 ≥5 倍事件"。曲线会自己回答"压到 10 个要付多少代价"。这是 OBSERVATION_PLAN §14.5 已定义但**从未真正画出**的图。
- **裁决**：双方都对，因为问题问错了。"越少越好"是伪命题，真命题是"**在给定预算下，如何让被看到的那个币的期望值最大**"——这是排序问题，不是数量问题。

#### 交锋四：该不该有固定止盈？

- **支持移动止损（A 组）**：海龟用 2N 止损 + 20 日退出，不设固定止盈，让利润奔跑。多倍币的本质是长尾，固定止盈会系统性砍掉右尾。
- **支持快速止盈（B 组）**：加密行情 4 天回吐 84%（TUT 案例），固定止盈是生存必需。
- **反方（H 组）**：两边都没有证据。项目从未算过任何一条持有期收益曲线，"该不该止盈"目前是纯信仰之争。
- **第三方验证方案（E 组）**：用 A1 r3 已修好的底表（含 7/30/90 天 `max_high`、`min_low`、`post_dd`），对同一批入选对象并排跑 4 条退出规则：固定 +50%、移动止损 2N、跌破 20 日均线、鱼尾信号（OI 骤降 + 基差 >30%）。**底表已有，不需要新数据。**
- **裁决**：在跑完之前，任何"应该止盈/应该拿住"的表述都应视为未验证。但可以先立一条：**止盈规则必须与发现规则分开评估**，不能因为"发现对了"就认为"退出也对"。

### 3.4 第四轮：激进组合（10 个，机制互补而非指标相加）

### 3.5 第五轮：研究假设库（30 张卡，暂不淘汰高风险方向）

> 卡片格式固定六栏，其中"增量"一栏合并了"挑战什么 / 与现有关系 / 是否改变上限"三问。
> **上限标记**：★★★ = 可能改变项目天花板；★★ = 明显改进；★ = 增量有限但便宜。

#### A 组 · 经典交易体系

**H01 · 关键点三段式** ★★
- **假设/机制**｜多倍行情需要"压缩 → 首次突破 → 回踩不破"三段齐备；只测第二段会把"假突破"当机会。
- **增量**｜挑战 `c_breakout` 的单点定义；与现有评分是替代关系（2 分改为三条件组合）；上限：中。
- **数据**｜已有 1h 线即可，无需新数据。
- **最小实验**｜在 822 正例 + 580 对照上构造 `compress_20d`（ATR 收缩比）、`breakout_first`、`retest_depth`（突破后 72h 最低回撤），三条件分别与组合的区分度。
- **判据**｜支持：组合区分度 > 单突破 +8pp 且样本外（≥2025）不翻转。推翻：组合与单突破无差异，或回撤深度与后续涨幅无单调关系。
- **失败留存**｜若回撤深度无用，则"洗盘"至少在 72h 尺度上不可观测，直接约束 H08/H10 的设计。

**H02 · 风险单位与金字塔** ★★

- **增量**｜替代"是否爆拉"的二分类；上限：中高（改变输出形式）。
- **数据**｜已有 1h 线（3,140 文件）。
- **最小实验**｜用 DTW 或归一化欧氏距离，对 2026 年样本检索 2022–2024 最相似的 50 条路径，看其后续收益分布是否有预测力。
- **判据**｜支持：检索组的后续收益分位显著偏离基准。推翻：无偏离。
- **失败留存**｜可验证"历史相似性"是否有多倍币研究价值。

**H25 · 多专家竞争** ★★
- **假设/机制**｜趋势/事件/挤压三类专家各自出名单，按近期表现动态加权；承认没有单一最优逻辑。
- **增量**｜替代单一评分；上限：中高（鲁棒性）。
- **数据**｜需先有至少两个可独立运行的专家（H06/H09 与 H03）。
- **最小实验**｜先用两个专家（趋势 + 跨所）各出 top20，比较并集与交集的十倍覆盖。
- **判据**｜支持：并集覆盖 > 任一单独专家 +10%。推翻：交集已含全部十倍（说明专家冗余）。
- **失败留存**｜得到"多逻辑是否互补"的第一手证据。

#### F 组 · 社区与田野

**H26 · 假阳性解剖** ★★★
- **假设/机制**｜研究"看着会涨但没涨"的样本，比研究正例信息量更大（样本量大 10 倍，且正是系统每天误报的那批）。
- **增量**｜项目只有正例+随机对照，没有"同形态失败"专项；上限：高（直接降低误报成本）。
- **数据**｜需构造：在 822 正例的 `pre_day` 特征分布上，找**特征相同但 label=0** 的样本（现有 580 对照已部分满足）。
- **最小实验**｜用倾向得分匹配，从对照中挑出与正例特征最接近的 200 条，比较两组在"更细粒度特征"（taker、单笔规模、基差）上的差异。
- **判据**｜支持：能找到 ≥1 个在两组间显著不同的细粒度特征。推翻：两组在所有细粒度特征上都相同（说明现有特征已饱和）。
- **失败留存**｜这是本报告认为**最可能产生新知识**的一条，无论成败都会留下"误报的可解释性"结论。

**H27 · 链上净流入** ★★
- **假设/机制**｜交易所钱包净流入/巨鲸建仓是真实资金证据。
- **增量**｜项目明确列为"成本最高"；上限：高但成本高。
- **数据**｜需新数据（Arkham/Nansen/Glassnode），付费。
- **最小实验**｜只取 10 个十倍案例，人工核对链上是否在启动前有净流出交易所的行为。
- **判据**｜支持：≥7/10 呈现同向。推翻：随机。
- **失败留存**｜10 个样本只能生成假设，不能验证；明确标注为"待大样本"。

**H28 · 叙事生命周期** ★
- **假设/机制**｜叙事从"新概念"到"人人皆知"有固定时间尺度，早期介入收益最高。
- **增量**｜项目完全无叙事维度；上限：中（难量化）。
- **数据**｜Google Trends / 社交提及量，成本中。
- **最小实验**｜取 5 个叙事（RWA/AI/DeFi 等），看板块指数与提及量的领先滞后。
- **判据**｜支持：提及量领先价格 1–4 周。推翻：同步或滞后。
- **失败留存**｜多半只能得到"叙事是同步指标"，价值有限。

**H29 · 做市商指纹** ★
- **假设/机制**｜同一批币的"拉—横—再拉"节奏可识别（事件间隔、回撤深度分布）。
- **增量**｜项目无"同一操盘方"概念；上限：中高但难验证。
- **数据**｜已有事件库（841 条，396 币）。
- **最小实验**｜聚类事件的"间隔—回撤"二维分布，看是否出现稳定簇，且簇内币种是否重叠。
- **判据**｜支持：存在 ≥3 个稳定簇且簇内币种显著重叠。推翻：无结构。
- **失败留存**｜可证伪"做市商风格"是否可从公开数据识别。

#### G 组 · 跨学科

**H30 · 注意力预算（检索式排序）** ★★★
- **假设/机制**｜把每日候选当搜索结果页，优化"单位注意力捕获的期望收益"，而非覆盖率；核心指标是预算-覆盖曲线。
- **增量**｜直接替换"min_score 阈值"这一决策方式；与 H21 互补（一个定目标，一个定算法）；上限：高（改变整个交互范式）。
- **数据**｜A1 r3 底账（含每轮候选数与去向）。
- **最小实验**｜画预算-覆盖曲线：横轴每日看几个（5/10/20/50/100），纵轴保留的 ≥5 倍事件比例；同时画"随机抽"与"按现评分"两条基线。
- **判据**｜支持：现评分曲线显著高于随机，且存在明显拐点。推翻：与随机几乎重合（说明排序无价值）。
- **失败留存**｜这张图会成为项目后续所有"压缩候选"讨论的唯一基准。

## 4. 社区与公开材料研究

### 4.1 证据分级（先立规矩）

| 级别 | 含义 | 本报告用法 |
|---|---|---|
| **E1** | 可回溯的原始文本（本人公开笔记、书、演讲原文） | 可作为机制来源，仍需本地验证 |
| **E2** | 有出处的二手系统梳理（媒体复盘、研究博客） | 只用于定位原始材料，不作为证据 |
| **E3** | 社区自述、访谈转述、无时间戳的观点 | 只用于生成假设 |
| **E4** | 无法核实的说法、被转述多次的"名言" | **不采用** |

一条硬规则：**任何来自交易者的观点，都不能当作"已验证的盈利证据"**。本节的用途是提出机制，不是证明机制。

### 4.2 川沐：三处可直接映射到本项目的机制（E1）

来源：《川沐笔记 · 500 刀到 100w 刀 · 摘自推特语录》第 1.17 节（2023-12-09）、第 1.18 节（2023-11-11）及下集（2023-11-12），转载于 `zhuanlan.zhihu.com/p/682040949`。原文自述为"个人经验总结记录，不构成投资建议"。

**（1）十倍币的跨所资格条件——与本项目的死配置完全对应**

原文列举当时"持续爆拉数倍十几倍"的 6 个标的：`trb、gas、auction、ordi、bigtime、blur`（2023-12-09 时点）。归纳出两条：

> "它们在币安和 ok 同时存在（小交易所不计）"
> "他们不管开始在币安有没有现货或者合约，他们一定在 ok 有合约"
> 总结条件：**"币安 ok 同时有，且 ok 必须有合约"**

他给出的机制解释（原文要点）：这类资金"喜欢在币安和 ok 玩，很重视 ok 有合约与否"，因为这样可以"提前在 ok 建多仓"，再借两家的关系"给代币间隔地提供利好，比如币安开合约、币安加现货"；同时"即使单个平台出现下架或者其他风险，他们也能在另外一个平台消化掉"。他举 GFT 为例，称其"符合这个标准，是庄家操纵的极好的壳子"。

**与本项目的关系（这是本轮最重要的对照）**：
- `binance_box_strategy.py` 已经在算"币安+OKX 合约"标记，也有 `okx_quote_volume`；
- `REQUIRE_OKX` 被读取但**从未参与任何判断**（死配置）；
- 也就是说：**外部实战者把"跨所"当核心资格条件，本项目把它当装饰性展示。**

需要说明的限制：这是 2023 年 12 月的 6 个样本，属于事后归纳，**没有对照组**，完全可能是幸存者叙事。所以它只能作为 H06 的假设来源，不能作为结论。但它的验证成本极低（字段已在内存里），值得优先测。

**（2）鱼尾（派发）的三个可观测特征——对应本项目完全没有的"卖出层"**

原文对"行情顶部"的描述：

> "合约持仓量先骤降再反升"（他解释为平多开空的过程）
> 期现价差"可能 30% 以上"，并举例"ygg 在这种阶段价格差达到了 50%，polyx 40%，loom 30%"
> "币价涨幅最快的时候链上动作反而消失或者很小"（准备砸盘前停止往交易所外提币）

他给的两个具体盘口案例：LOOM 现货最高 0.5、期货 0.41，一小时内期货砸到 0.2796（现货 0.366），随后几小时从 0.29 拉到 0.3866 追平现货；HIFI 期货从 2.6 砸到 1.3、现货维持 2，再反抽到 2 打平后暴跌。并附一句风险提示："在加密市场永远别做空"，以上只用于现货卖出止盈。

**与本项目的关系**：
- "OI 先骤降再反升"是**序列特征**，而项目所有特征都是单时点截面——这条在现有架构里根本无法表达；
- "期现价差"项目**从未计算**，尽管现货与合约价格同时在内存里；
- "链上提币消失"需要新数据，暂缓。
- 更重要的是：这三点全部用于**卖出**，而项目没有任何卖出逻辑。

**（3）暴跌后的位置规则——一个可直接检验的几何假设**

> "25%，就是指行情最高价的 25% 抄底"；"千万别在 50% 抄底"，"庄家吃的就是 50% 腰斩抄底的人，会让他们再腰斩一次"
> "从最低价反弹到最高价的 25% 附近可以认为反弹行情开始"

他给的实例：LOOM 最低为最高价的 20%（0.5→0.1，反弹 0.16，收益 60%）；HIFI 18%（2.63→0.48，反弹 1.34，收益 179%）；YGG 18.12%（1→0.1812，反弹 0.438，收益 141%）；ORDI 29%（14→2.82，反弹 22.7，收益 700%）。同时明确限定：该比例"在韩国 upbit 操盘过的币中比较实用"，"在排放币中不太适用"，"扩大时间范围后可能不具有适用性"。

**评价**：这是一条**几何化的、可批量检验的**规则（回撤到前高 25% 附近 vs 50% 附近的后续反弹分布），而且它的自我限定非常诚实。它属于 H20（清算瀑布）的邻近假设，但**样本只有 4–6 个**，且限定条件极强。建议只在"高倍行情后暴跌"的子集上检验，不要外推。

**（4）另一份二手梳理（E2，仅作参考）**

雪球 2026-07-02 的系统梳理（`xueqiu.com/3457984033/398031515`）把川沐的框架概括为"以风险收益比（risk-reward）为核心"，并列了 CRCL / SBET / 01788.HK 的具体交易记录（如 CRCL 6 次交易合计约 165 万美元、SBET 单只 80–100 万美元以上）。**这些数字来自第三方复盘，未经独立核实，本报告不作为证据使用**。可迁移的只有一条原则：**决策问句不是"会不会涨"，而是"涨了赚多少、跌了亏多少、比值是否值得"**——这与本项目"用覆盖率衡量一切"的目标函数形成直接冲突（见 §2.3 M）。

### 4.3 浪浪：证据不足，不作为机制来源（E3）

可核实到的只有其微博账号（`weibo.com/u/7745408684`）的自我描述："BN、OK（A8 交易员）｜曾经的大号@数字浪浪人 始于交易、败于交易、成于交易"。除此之外，检索到的多为课程转售页与二手推荐文，**没有可回溯的原始交易记录或带时间戳的观点**。

**结论**：本报告不引用其方法。如果后续要研究，正确做法是抓取其历史微博/直播的时间戳观点，做"观点—价格"的前瞻性对齐，而不是读课程大纲。这项工作本身就是一个可执行的研究项（见 §10 的"原始材料时间戳化"）。

### 4.4 Ansem：注意力即供给控制（E2）

可核实事实：2026-06 在 Solana 发行 `$ANSEM`，市值一夜升至约 9,000 万美元；其公开钱包持有约 65% 供应量（当时价值超 5,000 万美元）；向 50 万以上钱包空投，相关方自行完成空投（新浪财经 2026-06-28 / 06-29 转述）。

**可迁移的机制**：这不是"技术形态"案例，而是"**分发即供给控制**"案例——通过大规模空投把筹码分散到海量地址，同时创始人地址保留绝对多数，形成"高名义分散 + 实际集中"的结构。它对本项目的启示是：**"持币地址数"这类看似分散的指标可能完全误导**，真正的约束是"前 N 大地址 + 可流通比例"。

**证据限制**：这是单案例、且发生在项目研究范围（币安现货）之外（Solana meme），**不能直接用于币安标的的评分**。它的价值在于提示一个被忽略的维度：筹码分布结构。

### 4.5 Murad：叙事周期论（E2）

可核实事实：Murad Mahmudov 在 Token2049 Singapore 2024 提出"memecoin supercycle"，主张 meme 币将进入超越 BTC/ETH 的超额表现阶段（Bitcoin Magazine 2024-10-11；PANews 2024-12-27）。同期存在明确反对意见：Dogecoin Foundation 的 Angel Versetti 批评该理论"建立在投资者集体心理与非理性之上"（转述见 2024-10-18 中文报道）。

**对本项目的意义**：Murad 的框架解释的是"**为什么某一类资产整体会被重估**"，属于 regime 层，不是个币层。它对应 H14（宏观开关）与 H28（叙事生命周期）。**但它不可操作**——"叙事"没有统一定义，也无法在币安现货数据里稳定度量。任何试图把它做成评分的尝试，都会退化成"用涨幅解释涨幅"。

**明确反对**：本报告不采纳"叙事驱动"作为核心评分维度，只采纳其作为**预算层的一个开关**（今天要不要出手），且必须用可量化代理（板块指数、BTC 主导率）而非人工判断。

### 4.6 经典交易体系：能迁移什么，不能迁移什么

| 来源 | 可迁移机制 | 迁移到加密会失效的地方 |
|---|---|---|
| 利弗莫尔（《股票作手回忆录》1923 /《How to Trade in Stocks》1940） | 关键点、试探性建仓、只在盈利头寸上加仓、不摊平亏损 | 他的"关键点"依赖**固定流通盘**与**连续报价**；加密的流通盘会因解锁突变 |
| 海龟（Dennis/Eckhardt，规则已公开） | 55 日突破入场、20 日退出、2N 止损、每 0.5N 加仓、单笔风险 1–2% | 趋势跟踪在**均值回复型**山寨币上会连续被打；且加密波动率结构非平稳，2N 会频繁触发 |
| Ed Seykota | 趋势跟随、风险单位化、"每个人得到他想要的" | 无失效点，但需要长周期与多品种分散，单市场难复制 |
| 索罗斯 | 反身性、盛衰序列（boom-bust） | 反身性不可直接量化；把它做成指标必然变成"事后叙事" |
| Paul Tudor Jones | 200 日均线定方向、5:1 风险收益比、防守优先 | 200 日均线在上市不足 200 天的新币上不可用——而这正是本项目的主战场 |
| William O'Neil | 杯柄形态、枢轴点（pivot）买入、突破日成交量 +40–50%、7–8% 止损 | 杯柄需要**数月**构筑；加密多倍行情的构筑期常以**周**计，形态尺度不匹配 |
| Mark Minervini | VCP（波动收缩）、趋势模板（价在 150/200 日线上、距 52 周高点 <25%、相对强度靠前） | 趋势模板需要 200 日历史；大量标的上市不足一年，会被系统性排除 |
| Linda Raschke | 波动率扩张、80-20 交易者、模式失效即离场 | 她的方法高度依赖盘中微观结构，与 1h 归档数据粒度不匹配 |

**三条跨体系共识（可直接用）**：
1. **只在盈利头寸上加仓，不在亏损头寸上摊平**——这条与"多倍币靠加仓放大"直接相关（H02）。
2. **风险单位化**：同一个信号在不同波动率标的上应给不同仓位（H02）。
3. **退出规则必须事先定义**，不能临场判断（H05）。

**一条跨体系共同盲区**：所有经典体系都假设"标的的供给是给定的"。加密里供给是**内生变量**（解锁、增发、销毁、跨链桥释放）。所以"波动收缩 = 供给枯竭"这个 VCP 的核心前提，在加密里**可能根本不成立**——收缩可能只是"还没到解锁日"。这是本项目可以做、而经典体系给不出答案的地方。

### 4.7 社区研究的方法论提醒

1. **幸存者叙事**：能讲出来的案例都是活下来的。川沐的 6 个币、Ansem 的 1 个币，都没有对照组。
2. **事后归因**：所有"因为 X 所以涨"的说法，在不知道"有 X 但没涨"的样本量前，都不成立。
3. **不可复现**：绝大多数社区方法没有给出"什么情况下不算数"。川沐的 25% 规则是少数给出了失效条件的（不适用排放币、不适用扩大时间范围），这一点值得学习。
4. **本报告的处理**：社区材料只用于生成 H06/H07/H08/H11/H20 五张卡，**不进入任何结论**。

## 5. 颠覆性假设清单（10 条，专门挑战现有框架）

| 编号 | 假设 | 挑战的是什么 | 为什么可能对 |
|---|---|---|---|
| **D01** | 真正该预测的不是"涨不涨"，是"**能不能进得去、出得来**" | 整个评分体系 | 收益上限由流动性与深度决定；一个 20 倍但无法成交的标的等于 0 |
| **D02** | 最优结构可能是**多套互斥逻辑竞争**，而不是一个统一评分 | `WEIGHTS` 单一真源的设计哲学 | 趋势、事件、挤压三种机制的最优特征集不同，强行加权会互相抵消 |
| **D03** | 应重新定义"值得捕捉的行情"：用"**信号后可获空间 / 最大回撤**"替代"低点到高点倍数" | 事件标签本身 | 现有标签奖励"低点买入"这个不可实现的动作 |
| **D04** | 优化顺序应反过来：**先保证大赢家不漏，再压缩候选** | "减少人工候选"这一优先级 | 项目当前先压候选再谈覆盖，长尾必然先被牺牲 |
| **D05** | 从"**空头会被迫平仓**"反推，比从"什么会涨"正推更可观测 | 多头视角的整个研究 | 挤仓条件（低流通 + 高 OI/市值 + 负费率）是可观测的物理量 |
| **D06** | 把"**上币/下架/开合约**"当唯一外生变量，其余全部条件化 | 技术指标的核心地位 | 外生事件有时点、可归档、不可被指标替代 |
| **D07** | 用"**时间到事件**"（hazard）模型替代二分类 | "是/否爆拉"的标签设计 | 输出"未来 T 天内启动的概率"比"是否"信息量大得多 |
| **D08** | 承认不可预测，转向"**凸性参与**"：小额广撒 + 严格单次损失上限 | 命中率导向的评价体系 | 长尾分布的期望值由右尾决定，不需要高命中率 |

## 7. 最小实验方案（5 个，全部零新数据）

> 统一约束：①只用 `pre_day` 及之前的数据；②时间切分固定 训练 <2025-01-01 / 测试 ≥2025-01-01；③所有基线同时跑"现评分""随机""趋势单条件"三条；④结果文件写入 `research_committee/out/`，**不覆盖任何现有产物**；⑤参数在跑之前写进实验卡，跑完不改。

### E1 · 订单流三特征（H17/H18/H19）

- **要回答的问题**：主动买入占比、平均单笔规模、薄盘度，是否提供超越"趋势"的独立信息？
- **数据**：`data/1h/*.parquet`（3,140 文件）的 `taker_buy_quote`、`quote_volume`、`trades`；标签与样本键沿用 `data/features.csv` 的 `(symbol, pre_day)`。
- **构造**（全部用 `pre_day` 23:00 前已收盘的 24 根）：
  - `taker_ratio_24h = Σtaker_buy_quote / Σquote_volume`
  - `avg_trade_size = Σquote_volume / Σtrades`
  - `thinness = |close_t/close_{t-24} - 1| / Σquote_volume`（单位成交额换来的波动）
- **基线**：现 `score_full>=5`；`c_trend` 单条件；同数量随机（固定种子）。
- **判据**：①三个特征各自按五分位，爆拉率单调；②在 `c_trend` 分层后仍显著（层内差 ≥5pp）；③2025+ 样本方向一致。
- **失效条件**：`taker` 缺失（1,402 中 678 条无值）若集中在 2022–2023，则只能用于近期子集，**必须显式标注**，不能混入全样本结论。
- **成本**：半天。**产出**：`out/e1_orderflow.csv`、`out/e1_report.md`。
- **为什么排第一**：数据已在本地、字段已被证明有信号（+5.8pp）、且与现有评分完全正交。

### E2 · 条件交互复活检验（H13/H22）

- **要回答的问题**：7 个"已作废"条件，是否在某些条件下仍然有效？负费率是否是挤压燃料？
- **数据**：`data/backtest_scores.csv` 全字段（含 `funding_neg_ratio_7d`、`oi_cap_ratio` 来源列 `oi_value`/`price`）。
- **方法**：对每个被否决条件，与 `c_trend`、`oi_chg_1d` 各做 2×2 分层；每格算"爆拉率 − 该格基准率"。样本量 <150 的格子标"功效不足"，不解读。
- **基线**：该条件的边际区分度（已记录值）。
- **判据**：任一格区分度 ≥+8pp，且 2025+ 同向，且格子样本 ≥150 → 记为"条件性有效"。
- **失效条件**：全部格子都回到 0 附近 → 确认"作废清单"是全条件作废，而非误杀。
- **成本**：半天到 1 天。**产出**：`out/e2_interaction.csv`（条件 × 分层 × 训练/测试）。

### E3 · 预算-覆盖曲线（H30/H03）

- **要回答的问题**：在"每天只看 N 个"的约束下，现评分到底比随机好多少？拐点在哪？
- **数据**：A1 r3 底账（含每轮候选与去向）+ `data/backtest_scores.csv`。
- **方法**：对每个交易日，按三种排序各取 top-N（N=5/10/20/50/100/200），统计"被选中且 30 天内出现 ≥2/3/5/10 倍"的事件数；画三条曲线 + 随机基线。
- **判据**：①现评分曲线在 N=20 处显著高于随机（差值 >2 个标准误）；②存在明显拐点（N 增加而覆盖不再上升）；③同一张图能回答"压缩到 10 个要付多少代价"。
- **失效条件**：曲线与随机几乎重合 → 排序层无价值，全部精力转向资格层。
- **成本**：1 天。**产出**：`out/e3_budget_curve.csv` + 一张图。
- **为什么重要**：这是 OBSERVATION_PLAN §14.5 已定义、但**从未真正画出来**的核心验收图。没有它，所有"减少候选"的讨论都是拍脑袋。

### E4 · 退出规则对照（H05/H08）

- **要回答的问题**：固定止盈、移动止损、均线退出、鱼尾信号，哪条在同等回撤下保留右尾更多？
- **数据**：A1 r3 底表（`max_high` / `min_low` / `post_dd` / `gap_hours`，7/30/90 天）。
- **方法**：对同一批入选对象，用参考价（t+1h 开盘）起算，跑四条规则；输出净值、最大回撤、右尾（≥5 倍）保留率、平均持有小时数。
- **判据**：某规则在最大回撤 ≤ 基线的前提下，右尾保留率高出 ≥10pp。
- **失效条件**：四条无差异 → 退出层不重要，重心回到发现（这是有价值的负结论）。
- **成本**：2 天。**产出**：`out/e4_exit_rules.csv`。
- **前置**：必须先确认底表的 `ref_ts` 与 `complete_30d` 口径（r3 已修好，可直接用）。

### E5 · 假阳性匹配解剖（H26）

- **要回答的问题**：特征几乎相同、结局却不同的两组样本，差在哪？
- **数据**：822 正例 + 580 对照 + E1 产出的三个订单流特征。
- **方法**：倾向得分匹配（以现有 6 个评分字段为协变量），从对照中挑 200 条与正例最接近的；比较两组在 E1 三特征 + `basis`（若有）+ `oi_cap_ratio` 上的差异。
- **判据**：找到 ≥1 个变量在两组间差异显著（p<0.05 且效应量 ≥0.2 SD）。
- **失效条件**：全部无差异 → 说明现有特征集已饱和，误报不可解释，只能靠"扩大参与面"应对。
- **成本**：2 天。**产出**：`out/e5_false_positive.csv`。
- **为什么值得做**：项目每天误报的币远多于真爆拉，**误报样本的信息量天然比正例大**。

### E6（可选）· 跨所资格（H06）

- **卡点**：需要"历史某日 OKX 是否已上线该币及其合约"，现有归档没有。可先做**当前截面**的弱检验（当前双所标记 vs 近 90 天涨幅），但**不能替代历史检验**。
- **若要做**：从今天起每日快照 `okx.load_markets()` 与币安合约列表，30 天后即可开始积累；或买历史上市数据。
- **成本**：当前截面半天；历史版本需要 1 个月的数据积累。

## 11. 三个问题的回答

### Q1. 如果只能改变项目的一项核心能力，最值得调查什么？

**答：建立"结构资格层"——先判一个币在物理上能不能翻数倍，再谈它现在强不强。**

理由不是直觉，是四条本地证据的交汇：

1. 十倍组 K 线均分 **4.25**，低于 2–3 倍组的 **5.17**——评分越高，反而越不像十倍；
2. 十倍组"突破箱体"命中 **0%**——现有核心条件对最大赢家完全失效；
3. 24 个十倍事件里 **10 个总分恰好 5**——它们是"刚好过线"，不是"高分选中"；
4. 822 个正例里 **65.8%** 缺完整合约字段——评分对三分之二的样本根本无法完整计算。

四条合起来指向同一个结论：**这些赢家是被"进入池子"这件事捞到的，不是被"分数高"选出来的。** 那么唯一能改变上限的动作，就是把"进入池子"这件事从"成交额 0.5M–50M + 市值 <2B"这种粗糙代理，升级为真正的结构判据：流通比例、可流通筹码、OI/市值（已算未用）、跨所可达性（已算未用）、薄盘度（数据已有）。

而且这件事**不需要新数据就能开始**：`oi_cap_ratio` 与 OKX 字段已经在内存里，`taker`/`trades`/`quote_volume` 已经在磁盘上。项目不是缺能力，是**把已经算出来的资格信息丢掉了**。

### Q2. 哪些被忽略的研究方向，最可能改变这个项目的上限？

按"可能改变上限 × 现在完全没做"排序，三个：

1. **序列与路径特征**（H01/H04/H08/H20/H23）。项目所有特征都是单时点截面，而"启动前"本质上是一个**过程**：压缩→突破→回踩，OI 先降后升，基差先扩后收。这些在现有架构里**无法表达**。这不是"再加一个指标"，是"换一种特征表示"。而它可能同时解决"箱体类条件被证伪"和"十倍组分数更低"两个矛盾——因为被证伪的是静态量，不是过程。

2. **供给结构（流通比例 / 解锁 / 筹码集中）**（H11/H12）。这是唯一一类"物理约束"而非"统计信号"。它回答的是"能不能翻倍"，而不是"会不会现在涨"。经典交易体系在这里全部失效（它们假设供给固定），所以这是本项目相对外部方法论**真正的比较优势**所在。代价是需要新数据，但可以先从当前截面开始。

3. **退出与持有层**（H05/H08）。收益集中度 51.4%（含伪影，需复核）说明少数极端赢家决定结果。如果退出规则能多保留 10pp 的右尾，其对复利的影响可能**大于**把命中率从 6% 提到 7%。而项目对此完全是空白——不是做错了，是没做。

### Q3. 我们有哪些尚未意识到、但一旦弄清楚就可能显著改变研究方向的问题？

五个，按"一旦确认会推翻多少现有工作"排序：

1. **市值闸门在回测中从未生效。** `11_hit_rate_current.py` 读 `market_cap` 列，但 `features_audit.csv` 没有这一列，`gate_cap` 恒为 True。这意味着"CANDIDATE_POOL_CHANGE 里市值上限 2B 的历史效果"**从未被验证过**，而这条闸门正在实盘里砍掉标的。如果市值上限实际上砍掉了大量十倍机会（历史上十倍币启动时市值最大约 1.5B，很接近 2B 上限），那么整个扩池决策的前提就是错的。

2. **"发现"与"持有"共用同一个分数，而它们的最优解可能相反。** 发现奖励变化率（越突然越好），持有奖励结构稳定（越不破越好）。用同一个 `score` 做两件事，必然在其中一件上是错的。项目从未把二者分开建模，甚至没有意识到它们是两个问题。

3. **事件标签本身在制造研究目标。** `pre_day = 启动日 − 1`，而"启动日"是事后定义的（低点之后第一根涨 15% 的 K 线）。这等于要求"在启动前一天必须有信号"。对于"慢涨后爆发"型行情，这一天可能完全没有异动——于是这类行情被系统性地排除在正例之外，不是因为它们不可发现，而是因为**标签定义不承认它们**。TODO B1 提到了这一点，但没意识到它影响的是整个样本空间。

4. **研究库与实盘池的样本空间不同。** 研究库含已下架币（ALPACA 45.68x 就在里面），实盘只能看当前上市标的。于是"下架前最后一拉"这类被复盘报告明确记录的高倍模式，**在实盘系统里结构上不可见**。所有基于全库得出的覆盖率结论，都必须标注"不含实盘不可见标的"——而目前没有任何一份报告这样做。

5. **收益集中度的计算含数据伪影。** 前十涨幅占比 51.4%，其中 IOTX 2025-10-10 记为 16,360 倍（低点 0.000001 → 0.01636），但到 10-13 收盘后最高仅约 1.07 倍。前十里有 7 条用了同一天的极端低点。这意味着**任何均值型指标（平均涨幅、期望收益、集中度）都可能被伪影支配**，而项目的多数结论用的是均值。
